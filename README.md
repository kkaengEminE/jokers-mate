# Joker’s Gambit — PHASE 1

상태: **규칙 문서 초안 / 승인 대기** · 작성일: 2026-10-20 (Asia/Seoul)

표준 체스의 기물에 플레잉 카드 정체성을 부여하고, 살아남은 기물의 카드 다섯 장으로 포커와 가상 골드 베팅을 진행하는 2인 게임이다. 브라우저 2D 프로토타입을 먼저 만들고 향후 Steam 출시를 검토한다. React, TypeScript, chess.js는 선호 스택이며 아직 설치하거나 구현하지 않았다.

## 이번 저장소의 범위

README 및 docs/01~06은 상세 초안이다. docs/07~14는 후속 설계를 위한 개요만 제공한다. OPEN_QUESTIONS는 승인 필요한 선택, DECISION_LOG는 확인된 결정과 출처를 기록한다. 게임 코드, 실행 환경, 패키지, 아트, 배포는 포함하지 않는다. 최초 Phase 1에서는 로컬 Git만 초기화했다. 이후 사용자 요청으로 개인 계정 kkaengEminE의 비공개 GitHub 저장소에 문서를 커밋·푸시한다. 게임 구현은 여전히 승인 대기다.

## 승인 상태 표기

- **확정**: 조회된 사용자 발언 또는 사용자가 이번에 준수하도록 지정한 [TO CODEX] 명세의 명시 규칙.
- **도출**: 확정 규칙의 논리적 결과. 새로운 게임 규칙 승인으로 간주하지 않는다.
- **제안 / 승인 대기**: 구현 가능한 후보 모델. 승인 전 제품 기본값으로 채택하지 않는다.
- **미확인**: 원문을 조회할 수 없어 승인을 입증할 수 없는 사항.

## 출처와 우선순위

현재 사용자 지시 → ‘이상한나라 여왕 비교’의 확인 가능한 승인/정정 → [TO CODEX] 명세 → 이 문서의 제안 순으로 해석한다. 이전 대화의 “규칙 충돌은 추천대로”라는 발언은 확인했으나 추천 답변 본문은 참조 표식으로만 반환되었다. 따라서 해당 세부안을 추정하여 확정하지 않는다. 확인 가능한 골드 정정은 명세와 일치한다.

- ‘이상한나라 여왕 비교’: conversation 6ad720a4-3df4-83e8-acc6-23a14025974f
- ‘Document Game Rules’: conversation 6ad768ac-b7a0-83ec-b203-e93dfde5d7a8
- 출처별 발언 ID와 적용 범위는 DECISION_LOG 참조.

## 검토 기준과 다음 단계

총 골드 보존, 체스 합법성, 포커 전환 시 최소 5기물, 카드 정체성 유지, 비공개 정보 차단을 함께 검토한다. 경제 모델은 계산 예시와 수학적 불변식을 제공하되 승인된 구현이 아니다. 다음 단계는 Q01~Q06 결정과 누락된 추천안 확인이며, 승인 전 PHASE 2를 시작하지 않는다.
