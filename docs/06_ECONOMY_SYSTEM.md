# 06 · 경제 시스템과 정산 — R4

2026-10-24 반영. 사용자 선택: **“폴드 손실 유지: 최소 잔액 보장 없이 50G·40/60 적용”**. 기존 R3(20G·30/10)를 새 판에서 대체한다. 검토25의 최소50G 보장안은 채택하지 않았다.

## 입장과 지급

- 판마다 각자 **50G를 한 번만** 중앙에 예치한다. 합계100G이며 수수료가 아니다.
- 체스 승자 **40G**, 포커 승자 **60G + 유효 추가 베팅**. 이 금액들은 양측을 합친 배당이다. 개인별로 대응시키면 체스20/포커30이나 별도로 두 번 걷지 않는다.
- 체스는 결과와 받을 몫만 확정한다. 포커 전환에 추가 참가금은 없고, 포커 종료 뒤 한 번만 지급한다. 체스 배당은 이번 판 베팅에 재사용하지 못한다.
- 체스 무승부: **전체100G + 유효 추가 베팅**을 포커 승자에게 지급한다.
- 최소 잔액 보장은 없다. 다음 판에 필요한50G 미만이면 파산, 정확히50G면 참가 가능. 남은1~49G를 몰수하지 않는다. 플레이어·로언·황제에 동일 적용.
- 5판마다 참가금 인상 없음. 최소 추가 베트·정규 인상폭은 기존20G 유지.

## 보존 정산식

Bᵢ=시작 잔액, Cᵢ=참가50 포함 누적 투입, 50≤Cᵢ≤Bᵢ.
m=min(Cw,Cb), 미매칭 반환 Rᵢ=Cᵢ−m.
체스 배당 Aᵢ=체스 승자40/패자0, 무승부면 양측0.
포커 팟 P=2m−ΣA, 포커 배당 Wᵢ=포커 승자P/패자0.

**Fᵢ=Bᵢ−Cᵢ+Rᵢ+Aᵢ+Wᵢ**. ΣF=ΣB, F≥0. 보호 보정은0. 포커 무승부는 허용하지 않는다. 금액은 안전한 정수 범위로 검사하며 합계를2000으로 고정하지 않는다.

체크는 추가로 안 거는 행동이며 기존 팟을 없애지 않는다. 서로 체크하면 쇼다운. 폴드는 포커 배당 권리를 상대에게 넘기며 확정된 체스 배당은 유지한다. 손실은 개인 포커 몫30과 이미 맞춘 추가 베팅이며, 체스무라면 이월된 개인 체스몫20도 잃는다. 미매칭 초과액은 원래 주인에게만 반환한다.

## 도주

참가 후 최종 정산이 저장되기 전에 나가거나 새로고침하면 내 납부액C 전부를 잃는다. 체스 배당도 받지 못하고, 상대는 자기 납부액을 회수한다. 내최종=B나−C나, 상대최종=B상대+C나. 예: 각1000, 참가50만 납부 후 종료 →950/1050. 탭 숨김은 일시정지이며 도주가 아니다. 이미 저장된 정산은 보존한다.

## 저장·이행

경제 버전 `r4`를 새 게임·다음 판에 적용한다. 기존 저장 판(이전 참가 대기 화면 포함)은 기록된 경제 버전으로 마치며 화면에 이전 판임을 안내한다. 이전 정산 배당을 재계산해 바꾸지 않는다. 다음 판 입장 가능 여부는 새 참가금50G로 판단한다. 구버전 판에서 최종20~49G가 남아도 새 판에는 참가할 수 없다.
