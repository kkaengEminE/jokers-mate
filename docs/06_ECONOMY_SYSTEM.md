# 06 · 경제 시스템과 정산 검증

> Phase 1 설계 이력입니다. 후속 구현 요청에 따른 현재 적용값·상태는 [15_PROTOTYPE_DECISIONS](15_PROTOTYPE_DECISIONS.md)를 우선 참조하세요. 당시 승인 대기 표시는 역사적 기록으로 보존합니다.

## 확정 불변식

전체 게임 시작 잔액은 A=1000, B=1000이며 총량 2000이다. 각 판 참가금 20은 중앙 팟으로 이동한다. 체스 종료에는 지급하지 않고 포커 종료 후 한 번만 정산한다. 정산 전후 총량은 같고 음수 잔액은 없어야 한다.

체스 승자의 최종 잔액은 포커 결과와 무관하게 최소 20이다. 체스 무승부에는 보호가 없다. 20은 추가 보너스도 고정 환급액도 아니다. 정산 잔액 0~19는 전체 게임 즉시 패배, 정확히 20은 다음 판 참가 가능이다. 다른 사람의 미베팅 골드는 포커 승리만으로 가져갈 수 없다.

## E01 · 사후 하한 정산 모델 — 승인 대기 / Q01

다음은 확정 예시를 만족하는 **후보 알고리즘**이다. 미대응 반환 후 정상 포커 정산을 먼저 계산하고, 체스 승자에게 필요한 부족분만 상대의 팟 수령분에서 제외한다. 투입 한도를 사전에 20만큼 줄이지 않으므로 두 사람이 1000씩 투입한 표시와 20/1980 결과를 함께 설명할 수 있다.

### 입력과 원장

| 기호 | 정의 |
|---|---|
| Bᵢ | 이번 판 참가금 납입 전 잔액, 각자 최소 20 |
| Cᵢ | 참가금 포함 누적 투입액, 20 ≤ Cᵢ ≤ Bᵢ |
| Uᵢ | 미투입 금액 Bᵢ−Cᵢ |
| P | 원장상 총 팟 Cₐ+Cᵦ |
| W | 체스 승자 A/B/없음 |
| K | 포커 결과 A승/B승/동률; 폴드는 상대 승리로 매핑 |

원장 불변식 Uₐ+Uᵦ+P=Bₐ+Bᵦ=2000. 기존 판 결과를 다음 판 B로 넘기며 매 판 1000으로 재설정하지 않는다. 카드 새 배정 등의 판 초기화는 Q08이다. 정수 골드만 사용한다는 안은 Q06 승인 대상이다.

### 전제 검증

베팅 종료는 합법 행동 이력으로 입증되어야 한다. 콜 미완료를 임의 쇼다운으로 바꿀 수 없다. 승자·폴드 플레이어·체스 결과를 검증하고 정산 ID가 이미 처리되었는지 확인한다. 실패하면 일부 지급 없이 오류 상태를 남기는 원자적 처리를 제안한다.

### 순서와 수식

1. **미대응 반환:** m=min(Cₐ,Cᵦ), Rᵢ=Cᵢ−m. 반환은 원소유자에게만 귀속한다. 2인 게임이므로 추가 경합 상대가 없는 초과분을 사이드 팟으로 승자에게 주지 않는다.
2. **기본 보유액:** Hᵢ=Uᵢ+Rᵢ=Bᵢ−m. 반환 후 경합 팟 T=2m이다.
3. **통상 팟 배분:** 단독 승자에게 T, 패자에게 0을 배분하여 Xᵢ로 둔다. 폴드도 동일하다. 동률 분할안은 Xₐ=Xᵦ=m이다.
4. **정산 전 후보 잔액:** Fᵢ⁰=Hᵢ+Xᵢ.
5. **보호 부족분:** W가 없으면 d=0. W가 있으면 d=max(0,20−Fᵂ⁰).
6. **팟 내부 조정:** Fᵂ=Fᵂ⁰+d, 상대 Fᵒ=Fᵒ⁰−d. d는 상대의 Xᵒ에서만 차감하며 미투입액/미대응 반환액에서는 차감하지 않는다. d≤Xᵒ를 확인한다.
7. **단일 확정:** R, X, d의 상세 내역과 최종 F를 한 번에 기록하고 팟을 0으로 한다. 내부 계산 단계는 중간 지급 이벤트가 아니다.
8. **전체 게임 판정:** Fᵢ<20이면 즉시 패배. Fᵢ=20이면 계속할 자격이 있다.

### 왜 보존되는가

Hₐ+Hᵦ+T=Bₐ+Bᵦ이고 Xₐ+Xᵦ=T이므로 통상 정산에서 총량이 보존된다. 보호 단계는 +d와 −d를 동시에 수행하여 총량을 바꾸지 않는다. W가 패배하고 부족분이 발생할 때 d≤20이고, 참가금 때문에 m≥20, T≥40이므로 상대의 팟 수령액으로 충분하다. W가 이기면 Fᵂ⁰=Bᵂ+m≥40이므로 d=0이다. 동률 분할에서는 Fᵂ⁰=Bᵂ≥20이므로 역시 d=0이다.

이 증명은 양측 최소 20 참가, 2인, 별도 수수료 없음, 위 동률 분할이라는 전제에서 성립한다. 관전자 기부, 레이크, 추가 참가자 등은 범위 밖이다. 오류 데이터에 보호금을 새로 만들어 맞추면 안 된다.

### 보호는 베팅 매칭을 다시 계산하지 않는다

A와 B가 각 1000을 투입하고 A가 체스 승자·포커 패자라면 T=2000, d=20, 결과 20/1980이다. 보호된 20을 처음부터 A의 투입액에서 제외하고 980 대 1000을 다시 매칭하면 경합 팟은 1960이 되어, A가 둘 다 이겼을 때 B에게 20이 반환되는 1980/20 결과가 된다. 이는 두 경기 동일 승자가 모두 가져가는 예시와 충돌할 수 있다.

따라서 **E01에서는 보호를 투입 취소/재매칭으로 해석하지 않는다.** 이는 일반 포커에 없는 최종 수령액 특례다. 사용자가 이 의미를 승인해야 한다. 사전 예약 모델을 택하려면 ‘올인’의 의미, 매칭 한도, 예시를 다시 합의해야 한다.

## 폴드와 불균등 올인

불균등 기여의 초과분은 쇼다운뿐 아니라 폴드에서도 원소유자에게 반환하는 안이다. 예를 들어 A가 100, B가 20을 투입한 상태에서 B가 폴드하면 A의 80을 반환하고 40의 경합 팟을 A에게 준다. A 최종 1020, B 980이며 B의 나머지 980은 가져가지 않는다.

보호된 체스 승자가 폴드한 경우에도 잔액 하한은 적용한다는 것이 명시된 ‘결과와 무관’ 규칙의 자연스러운 해석이다. 다만 실제 베팅에서 도달 가능한 폴드 상황을 승인해야 한다. 올인 완료 후 자금 없는 플레이어에게 새 폴드를 허용하는 규칙은 이 문서가 추가하지 않는다. 아래 정산 단위 사례 중 행동 도달성이 별도인 행은 이를 표시한다.

잔액이 정확히 20인 체스 승자는 참가금 전액 투입 뒤 포커에서 패해도 E01에서 20을 유지한다. 계속 체스에서 이기면 반복 생존할 수 있다. 이는 하한의 결과이며 이를 막기 위한 추가 비용은 승인 없이 도입하지 않는다.

## UI와 원장 표시 제안

금고의 ‘미투입’, 중앙 ‘총 투입’, ‘미대응 반환 예정’, ‘경합액’, 체스 승자의 ‘최종 잔액 최소 20 보호’를 구분한다. 올인 직후 금고가 0이어도 보호가 사라지지 않는다. 포커 승자의 예상 최대 수령액은 상대 보호 부족분만큼 줄어들 수 있다.

정산 내역에는 참가금 포함 투입, 미대응 반환, 기본 팟 수령, 보호 조정, 최종 잔액을 보여준다. 마차/시종 애니메이션은 확정된 한 번의 정산을 연출하는 것이며 자체적으로 원장을 수정하지 않는 구조를 제안한다.

## 검증 상태

문서 작성 단계에서 수식·표 사례 및 유효 정수 입력의 표본 조합을 독립 계산으로 검산한다. 이것은 게임 코드 테스트나 엔진 통합 검증이 아니다. 카드/체스 행동 이력의 도달성, 저장 원자성, UI 표시는 승인 후 구현 단계 검증 대상이다. 실제 검산 결과는 REPORT에 기록한다.
