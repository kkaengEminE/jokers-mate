# 04 · 체스 시스템

## 확정 기반

8×8 표준 초기 배치, 각 16기물로 시작한다. 합법 이동, 킹 안전, 캐슬링, 앙파상, 승격, 체크메이트, 무승부를 지원한다. 킹을 잡는 수는 존재하지 않는다. MVP에는 체스 시계가 없다. chess.js는 선호 검증 기반이지만 버전/API 및 무승부 정책은 선정하지 않았다.

## 수 처리의 제안 순서

1. 종료된 판의 추가 입력을 거절한다.
2. 표준 체스 합법성을 검사한다. 자기 킹을 체크에 남기는 수는 5기물 특례로도 허용되지 않는다.
3. 하나의 완결된 수를 적용한다. 앙파상 캡처, 캐슬링 두 기물 이동, 승격 역할 선택을 포함한다.
4. 제거된 기물과 카드 공개를 반영한다. 승격은 카드 정체성을 유지한다.
5. 양측 생존 수와 수를 둔 후 상대 체크/체크메이트를 계산한다.
6. 체크메이트면 수를 둔 쪽 승리. 5기물과 동시라면 체크메이트 사유를 우선 기록한다.
7. 체크메이트가 아니고 어느 한쪽이 정확히 5라면, 체크가 있을 때 수를 둔 쪽 승리, 없으면 무승부.
8. 그 외 표준 종료를 판정한다.

**7과 8의 충돌 우선순위는 Q02 승인 대기다.** 체크메이트 우선과 단독 5기물 판정은 확정이지만, 같은 수의 반복 무승부 청구/자동 종료까지 우선순위가 확정된 것은 아니다. 구현 시 이 빈칸을 라이브러리의 단일 game-over 값으로 숨기지 않는다.

## 5기물 특례의 의미

일반 수는 자신의 기물 수를 줄이지 않는다. 따라서 정상 진행에서 임계값을 최초로 만드는 수는 6기물인 상대의 한 기물을 잡는 캡처다. 캡처한 쪽이 상대 킹에 체크를 남기면 그 체크가 응수 가능해도 즉시 승리한다. 발견 체크도 체크에 포함된다. 킹 캡처는 허용되지 않는다.

현재 체크 상태에서 상대 기물을 잡고 체크를 해소해 상대를 5개로 만들었지만 상대 킹에 체크를 주지 않으면 무승부다. 체크를 해소하면서 역체크까지 주면 특례 승리다. 체크를 해소하지 못한 캡처는 불법이므로 어떤 종료도 발생시키지 않는다.

정상 시작에서 즉시 종료 규칙을 지키면 두 플레이어는 포커 전환 시 각각 5개 이상 보유한다. 4개 이하 데이터는 변형 규칙으로 처리하지 말고 손상/잘못된 입력으로 분리한다. 로드된 5기물 상태를 계속 진행하는 것도 금지해야 한다.

## 표준 무승부의 승인 경계

스테일메이트, 반복, 수 제한, 데드 포지션 등에 대해 ‘표준 무승부’는 요구되었으나 청구형/자동형 적용, 합의 무승부, 기권은 상세 지정되지 않았다. 라이브러리의 insufficient-material 판정과 모든 데드 포지션 판정이 같은지 검증해야 하며 지원을 미리 단정하지 않는다. 5기물에서 먼저 멈추므로 많은 극소수 기물 포지션은 정상 흐름에서 도달하지 않는다.

## 검증 매트릭스

| ID | 선행 조건과 마지막 수 | 기대 |
|---|---|---|
| C01 | 상대 6→5, 체크 없음 | 무승부 |
| C02 | 상대 6→5, 피할 수 있는 체크 | 수를 둔 쪽 승리 |
| C03 | 상대 6→5, 체크메이트 | 체크메이트 승리 |
| C04 | 체크 중 합법 캡처로 탈출, 상대 6→5, 역체크 없음 | 무승부 |
| C05 | C04 + 역체크 | 특례 승리 |
| C06 | 자기 체크 남는 캡처 | 수 거부·골드/카드 변경 없음 |
| C07 | 상대 7→6, 체크 | 계속 진행(다른 종료 없을 때) |
| C08 | 상대 6→5, 앙파상 발견 체크 | 특례 승리 |
| C09 | 캡처 승격 6→5 | 승격 적용 후 체크/메이트 판정, 카드 유지 |
| C10 | 양측 >5에서 체크메이트 | 즉시 포커 전환 |
| C11 | 양측 >5에서 스테일메이트 | 체스 무승부·포커 전환 |
| C12 | 5기물 체크와 다른 무승부 동시 | Q02 전까지 기대 미확정 |
| C13 | 종료 이후 수 입력 / 4기물 로드 | 거부 또는 복구 절차, 정상 진행 금지 |
| C14 | 킹 캡처, 체크를 통과하는 캐슬링 | 거부 |
| C15 | 적법 캐슬링 | 카드 매핑 유지·기물 수 불변 |

이는 검증 설계이며 실행된 체스 테스트가 아니다. FEN/PGN 기반 재현 자료는 승인 후 엔진 선택 단계에서 준비한다.
