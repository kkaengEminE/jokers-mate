# 04 · 체스 시스템

## 기본

8×8 표준 초기 배치, 각 16기물로 시작한다. 합법 이동, 킹 안전, 캐슬링, 앙파상, 승격, 체크메이트, 무승부를 지원한다. 킹을 잡는 수는 없다. 체스 시계는 없다. 합법성 검증은 chess.js를 사용한다.

- 플레이어는 백, 컴퓨터는 흑으로 고정한다.
- 매 판 표준 배치에서 새로 시작한다.
- 기권·합의 무승부는 없다. 진행 중인 판을 포기하면 도주 패배로 정산한다([06 경제](06_ECONOMY_SYSTEM.md)).

## 수 처리 순서

1. 종료된 판의 추가 입력은 거절한다.
2. 표준 합법성을 검사한다. 자기 킹을 체크에 남기는 수는 5기물 특례로도 허용하지 않는다.
3. 한 수를 적용한다(앙파상 캡처, 캐슬링 두 기물 이동, 승격 역할 선택 포함).
4. 제거된 기물의 카드를 공개하고 포커 대상에서 뺀다. 승격은 카드 정체를 유지한다.
5. 양측 생존 기물 수와, 수를 둔 뒤 상대의 체크·체크메이트 여부를 계산한다.
6. **체크메이트**면 수를 둔 쪽 승리. 5기물 도달과 동시라도 체크메이트로 기록한다.
7. 체크메이트가 아니고 어느 한쪽이 정확히 **5기물**이면, 상대에게 체크가 걸려 있으면 수를 둔 쪽 승리, 아니면 무승부.
8. 그 외 **표준 무승부**를 판정한다: 스테일메이트, 3회 반복, 50수 규칙(모두 자동 처리), 기물 부족.

판정 우선순위는 체크메이트 → 5기물 특례 → 기타 표준 종료다.

## 5기물 특례

일반 수는 자기 기물 수를 줄이지 않으므로, 5기물을 처음 만드는 수는 6기물인 상대의 기물을 잡는 캡처다.

- 캡처한 쪽이 상대 킹에 체크를 남기면, 그 체크를 피할 수 있더라도 즉시 승리한다. 발견 체크도 포함한다.
- 체크를 받고 있던 쪽이 캡처로 체크를 벗어나며 상대를 5기물로 만들었지만 역체크가 없으면 무승부다. 역체크까지 주면 특례 승리다.
- 체크를 벗어나지 못하는 캡처는 불법이므로 아무 종료도 일으키지 않는다.

즉시 종료를 지키면 포커 전환 시 양측은 항상 5기물 이상을 가진다. 4기물 이하 상태는 변형 규칙이 아니라 손상된 데이터로 취급하고, 저장에서 불러온 종료 상태를 계속 진행하지 않는다.
