# 30 · 화면 구성 ASCII 와이어프레임

**검토용 설계안 / 이미지 생성 없음 / 화면 미구현.** [29 · 분석·금화 조작 규칙](29_GAMEPLAY_UI_REDESIGN.md)의 시각적 배치 초안이다. 각 그림은 독립 예시이며 같은 판의 연속 캡처가 아니다.

사각형은 위치와 정보의 우선순위를 뜻한다. 실제 테두리를 모두 그리라는 뜻은 아니다. 기존 정원·체카드·잉크선·양피지 그림체를 그 자리에 사용한다.

- `[문구]`: 누르는 버튼. `(10G)`: 금화 선택 버튼. `##`: 상대 카드 뒷면.
- 카드의 `S / H / D / C`: 스페이드 / 하트 / 다이아 / 클럽. 실제 화면은 기존 무늬 기호를 사용한다.
- `앞/뒤`: 공개 여부에 따른 작은 위치 차이. 카드가 다른 카드나 버튼에 가려지지는 않는다.
- `잠김`: 행동 불가. 금액과 이유를 함께 표시한다.

## A. 메인 — 첫 화면에서 무엇을 누를지 하나만 먼저 보이게


```text
+----------------------------------------------+
|                                    [메뉴]   |
+----------------------------------------------+
|                                              |
|               정원 배경                      |
|                                              |
|            JOKER'S MATE                      |
|         체스의 한 수, 포커의 한 장           |
|                                              |
|           [     게임 시작     ]              |
|                                              |
|         [플레이 방법]  [설정]                |
|                                              |
|              자동 저장                       |
|                                              |
+----------------------------------------------+
```

저장이 있으면 주 버튼은 `[이어하기]`, 그 위에는 `ROUND 3 · 포커 진행 중` 한 줄만 붙인다. `[새 게임]`은 보조 행동이다. 저장된 판을 덮어쓸 때만 확인한다. 규칙 본문·로드맵·검증 문구·긴 프롤로그를 시작 전에 띄우지 않는다.

## B. 참가 준비 — 장면 위 초대장, 별도의 설명 페이지를 만들지 않는다


```text
+----------------------------------------------+
| ROUND 01                           [메뉴]    |
+----------------------------------------------+
|            [정원/체스판 배경]                |
|                                              |
|             왕실 정원의 대국                 |
|                                              |
|        [백 기물]       [흑 기물]             |
|           나     VS     로언                 |
|         1,000G        1,000G                 |
|                                              |
|                 참가 50G                     |
|            내 금고 1,000 -> 950G             |
|                                              |
|        [      50G · 대국 시작      ]         |
|                                              |
|              [배당 안내]                     |
|                                              |
+----------------------------------------------+
```

참가금은 이 버튼을 눌렀을 때 한 번만 납부한다. `배당 안내`를 열면 체스40/포커60, 무승부 이월, 손익표를 읽을 수 있다. 다음 판도 같은 작은 준비 패널을 사용하며 새로운 긴 설명을 반복하지 않는다.

## C. 체스 — 판이 화면의 중심, 이동을 위한 별도 양식은 없다


```text
+----------------------------------------------+
| ROUND 01 · 체스           [?] [일시정지]     |
+----------------------------------------------+
| 로언 · 흑 950G                  잡은 카드 0  |
|                                              |
|        8   r n b q k b n r                   |
|        7   p p p p p p p p                   |
|        6   . . . . . . . .                   |
|        5   . . . . . . . .                   |
|        4   . . . . * . . .                   |
|        3   . . . . * . . .                   |
|        2   P P P P[P]P P P                   |
|        1   R N B Q K B N R                   |
|            a b c d e f g h                   |
|                                              |
| 나 · 백 950G                    잡은 카드 0  |
+----------------------------------------------+
| 내 차례 · 이동할 칸을 누르세요               |
| 선택: e2 폰 / H Q              [선택 취소]   |
+----------------------------------------------+
```

대문자는 백, 소문자는 흑을 뜻하는 와이어프레임 표기다. 실제 모바일은 기존 기물 아이콘+카드 표식, 데스크톱은 캐릭터를 쓴다. `*`는 선택 기물의 합법 이동 지점이다. 시계·무르기·합의 무승부 같은 새 행동은 넣지 않는다.

모바일 칸 안의 표식만으로 모든 정보를 읽게 강요하지 않는다. 기물을 탭하면 하단 선택 띠에서 역할·카드·좌표를 크게 확인한다. 잡은 카드와 수순은 눌러서 여는 보조 서랍이다. 매 차례 도움말 버튼이나 규칙책이 판 아래 큰 공간을 차지하지 않는다.

### 체스 종료 패널


```text
+--------------------------------------+
|          마지막 체스판은 그대로      |
|                                      |
|           체스 무승부                |
|         포커로 100G 이월             |
|                                      |
|       [판 보기]     [포커로]         |
|                                      |
+--------------------------------------+
```

종료 사유는 한 줄 또는 상세 열기로 제공한다. 체스 종료를 전체 판 승패로 부르지 않는다. `포커로`는 카드 선택으로 연결한다.

## D. 패 선택 — 다섯 자리 자체가 공개 순서를 설명한다


```text
+----------------------------------------------+
| 다섯 장 선택                    [?] [메뉴]   |
+----------------------------------------------+
|     [1:HQ] [2:CQ] [3:H5] [4:C5] [5:CK]       |
|       1차    2차    3차     끝     끝        |
|                                              |
| 선택 5 / 5                      투페어       |
+----------------------------------------------+
|           생존 카드 목록                     |
|     [HQ]   [CQ]   [H5]   [C5]                |
|     [CK]   [S2]   [D7]   [H9]                |
|     [S8]   [D3]   [...]  [...]               |
|        이 목록 안에서만 스크롤               |
+----------------------------------------------+
| [추천]  [순서 바꾸기]  [선택 비우기]         |
|            [ 이 패로 시작 ]                  |
+----------------------------------------------+
```

슬롯의 `1차/2차/3차/끝/끝`은 상대에게 공개되는 시점을 뜻한다. 플레이어는 처음부터 자기 다섯 장을 모두 읽는다. 카드 탭으로 선택·취소하고, `순서 바꾸기`에서는 두 슬롯을 차례로 눌러 교환한다. 필수 드래그는 없다. 선택하지 않은 상대 카드 정체는 보이지 않는다. 정확히 5장 생존해도 순서는 바꿀 수 있다.

## E. 모바일 포커 — 내 차례의 기본 화면

첫 라운드, 양측 참가금만 납부한 상태다. 포커 팟은60G이고 체스 배당40G는 별도로 보관되어 있다. 예시는 내가 인상50G를 준비한 모습이다.


```text
+----------------------------------------------+
| ROUND 01 · 포커 1/3        [?] [일시정지]    |
+----------------------------------------------+
| 로언 · 흑                              950G  |
|                                              |
|      [SA]  [##]  [##]  [##]  [##]            |
|       앞    뒤    뒤    뒤    뒤             |
|                                              |
|              [석조 금화 받침]                |
|                  팟 60G                      |
|             체스 확정 40G [잠금]             |
|                                              |
|      [HQ]  [CQ]  [H5]  [C5]  [CK]            |
|       앞    뒤    뒤    뒤    뒤             |
| 나 · 백 / 투페어                       950G  |
+----------------------------------------------+
| 내 차례 · 금화를 고른 뒤 베팅                |
| 준비 받침: 50G          확정 후 금고 900G    |
|                                              |
|    ( +10G ) ( +20G ) ( +50G ) ( +100G )      |
|                                              |
|  [최소] [되돌리기] [비우기] [전부]           |
|                                              |
|  [폴드]       [체크]       [50G 베팅]        |
+----------------------------------------------+
```

핵심은 하단 세 줄이다. **금화 선택 줄 → 준비 상태 → 행동 확정**이 같은 위치에 있다. 체크·콜·레이즈를 찾으려고 펼치는 메뉴가 없다. `[전부]`도 즉시 실행이 아니라 준비다.

자기 패는 전부 보이며 공개 카드만 앞으로 나온다. 상대의 공개 카드 면도 자기 공개 카드와 같은 밝기다. 미공개 카드 면만 어두워지고, 캐릭터의 흑/백 색은 공개 여부로 변하지 않는다. 중앙의 확정 배당 잠금 표시는 베팅 가능한 금고와 혼동되지 않게 작게 둔다.

### 준비하지 않았거나 10G만 골랐을 때


```text
+----------------------------------------------+
| 준비 0G · 최소 베팅 20G                      |
| ( +10G ) ( +20G ) ( +50G ) ( +100G )         |
| [폴드]     [체크]     [베팅: 잠김]           |
+----------------------------------------------+
| +10G를 한 번 눌렀음                          |
| 준비 10G · 10G 더 필요                       |
| [폴드]     [체크]     [베팅: 잠김]           |
+----------------------------------------------+
| +10G를 한 번 더 누르거나 [최소]              |
| 준비 20G                                     |
| [폴드]     [체크]     [20G 베팅]             |
+----------------------------------------------+
```

금화 한 번의 클릭마다 합법 행동이 바로 실행되면, 두 번째 금화를 고르기 전에 차례가 넘어간다. 그래서 ‘준비’와 ‘확정’을 나눈다. 유효한 금액을 준비했을 때만 베팅 버튼을 금색으로 강조한다.

## F. 상대가 베팅했을 때 — 콜 금액을 포함한 실제 지불액을 표시

내 누적 납부50G / 상대90G, 직전 인상40G인 예시다. 상대에게40G를 맞추고40G를 더 올리면, 내 금고에서 이번에 나가는 돈은80G다.


```text
+----------------------------------------------+
| 상대가 40G 올렸습니다 · 내 차례              |
+----------------------------------------------+
| 내 금고 950G                  콜 필요 40G    |
|                                              |
| 맞추기 40G + 더 올림 40G = 이번 지불 80G     |
|                          남는 금고 870G      |
|                                              |
|    ( +10G ) ( +20G ) ( +50G ) ( +100G )      |
|                                              |
|  [최소40] [되돌리기] [비우기] [전부]         |
|                                              |
|  [폴드]      [40G 콜]      [80G 내고]        |
|                           [ 레이즈 ]         |
+----------------------------------------------+
```

오른쪽은 두 줄짜리 **한 버튼**이다. `80G`를 이번에 내는데 `40G 레이즈`만 적어 차감액을 오해하게 만들지 않는다. 금화 줄은 추가 인상액을 더하며, 콜 금액은 자동 계산한다.

- 콜만 하려면 중앙 버튼 한 번. 준비한 인상 금화는 버리고40G만 낸다.
- +20G만 담으면 최소 인상40G 미달로 확정 불가다.
- 남은 금고가15G라면 `15G 콜 · 올인`처럼 실제 지출을 표시한다. 부족한40G를 입력시키지 않는다.
- 인상이 잠긴 상태는 이유를 짧게 표시하고 합법 콜·폴드만 실행 가능하게 한다.

+------------------------------------------------------------------------------------------------+

+------------------------------------------------------------------------------------------------+
|   상대 금고 910G                      로언 · 흑                       [잡은 카드]              |
|                                                                                                |
|                             [SA] [##] [##] [##] [##]                                           |
|                               공개1 / 비공개4                                                  |
|                                                                                                |
|        [정원 / 상대 인물]          [석조 금화 받침]           [정원 / 종자]                    |
|                                      팟 100G                                                   |
|                                체스 확정 배당40G 보관                                          |
|                                                                                                |
|                             [HQ] [CQ] [H5] [C5] [CK]                                           |
|                                 나 · 투페어 / 공개1                                            |
+------------------------------------------------------------------------------------------------+

금고·캐릭터·금화 받침은 정원 장면에 배치하고, 하단 조작바는 화면 폭을 과도하게 채우지 않는다. 전체 원장·규칙은 상시 사이드바로 두지 않는다. 1280×720에서도 동일한 버튼을 같은 순서로 찾을 수 있어야 한다.

### 모바일 가로 배치


```text
+--------------------------------------------------------------------+
| [ROUND / 내 차례]                    | [내 금고 / 콜 필요]         |
|                                     |                              |
|      상대 [SA][##][##][##][##]       |  (+10)  (+20)               |
|                                     |  (+50) (+100)                |
|              [금화 받침]             |                             |
|                                     | [준비액 / 남는 금고]         |
|      내 패[HQ][CQ][H5][C5][CK]       | [최소][되돌리기][전부]      |
|                                     |                              |
| [나의 족보]                         | [폴드][콜][베팅 확정]        |
+--------------------------------------------------------------------+
```

오른쪽 조작 영역을 실제로 확보한다. 세로 화면을 가로로 눕힌 뒤 전체를 축소해 글씨까지 작게 만들지 않는다.

## H. 공개 → 승패 → 정산을 분리

### H1. 마지막 공개 중


```text
+----------------------------------------------+
| 쇼다운 · 상대 4번째 카드 공개                |
+----------------------------------------------+
|      [SA] [D7] [HA] [H7] [##]                |
|                      ^ 새로 공개             |
|                                              |
|                팟 100G                       |
|           마지막 한 장까지…                  |
|                                              |
|      [HQ] [CQ] [H5] [C5] [CK]                |
+----------------------------------------------+
|             [공개 건너뛰기]                  |
+----------------------------------------------+
```

이미 공개된 앞의 세 장은 유지한다. 남은 카드를 내/상대 순서로 하나씩 공개한다. 새로 드러난 카드만 짧게 강조하며, 현재 카드가 읽히기 전에 다음 장을 빠르게 덮지 않는다. 내 미공개 카드도 내용은 계속 보이고 ‘상대에게 공개되는 순간’의 표식이 바뀐다. 행동바에는 베팅 버튼이 없다.

### H2. 승패를 보는 순간


```text
+----------------------------------------------+
|                 모든 카드 공개               |
+----------------------------------------------+
|         상대 패 다섯 장과 족보               |
|                                              |
|               포커 승리                      |
|         내 투페어 > 상대 원페어              |
|                                              |
|          내 패 다섯 장과 족보                |
+----------------------------------------------+
|               [ 계속 ]                       |
+----------------------------------------------+
```

앞의 카드 배열과는 별도의 승패 설명 예시다. 비교 이유는 실제 평가 결과에서 나온다. 같은 족보라면 `A 키커 우위`처럼 승부를 가른 정보만 쓴다. 결정하지 않은 상대 패·승률을 꾸며 표시하지 않는다. 현재 룰에서 포커 무승부를 정상 결과로 설계하지 않는다.

### H3. ‘계속’을 누른 뒤의 정산


```text
+--------------------------------------+
|            이번 판 -10G              |
|         내 금고 1,000 -> 990G        |
|                                      |
|         체스 승리  /  포커 패배      |
|                                      |
|            [정산 상세]               |
|                                      |
|     [다음 대국 준비]    [메인]       |
+--------------------------------------+
```

이 그림은 추가 베팅 없는 체스 승리·포커 패배 예시다. 포커 결과와 한 판의 순손익을 혼동하지 않게 한다. 상세를 열면 시작금·납부액·반환·배당을 확인한다. 잔액50G 미만이면 다음 대국 버튼 대신 기존 캠페인 조건에 맞는 실패/엔딩 행동을 표시한다.

## I. 도움말·설정은 어디에 두는가


```text
+----------------------------------------------+
| 일시정지                              [X]    |
+----------------------------------------------+
|               [계속하기]                     |
|                                              |
|  [플레이 방법]  [설정]  [대국 기록]          |
|                                              |
|            [저장하고 메인으로]               |
|                                              |
|              [새 게임]                       |
+----------------------------------------------+
```

플레이 방법을 누르면 먼저 `체스 / 카드 선택 / 금화 베팅 / 정산` 네 항목을 보여준다. 선택한 항목만 펼쳐 읽는다. 설정에는 이동 힌트·움직임·후속 사운드 설정을 둔다. 개발 메모·경제 버전·테스트 결과는 플레이 화면에 놓지 않는다.

## J. 공간과 가독성 검토 체크

- 주 화면에 긴 규칙 문장과 키보드를 여는 숫자 입력창이 없다.
- 금화 네 개를 누르는 영역과 실제 행동을 확정하는 세 버튼 영역이 구분된다.
- 내 금고·이번 지불액·콜 금액·팟을 서로 다른 이름으로 표시한다.
- ‘준비 받침’은 실제 판돈이 아니다. 담은 금화를 비우더라도 이미 낸 돈은 돌아오지 않는다.
- 작은 화면에서는 배경·캐릭터 장식이 먼저 줄어든다. 카드 숫자·무늬·핵심 버튼의 크기는 지킨다.
- 기본 화면의 행동을 찾기 위해 본문 스크롤·접힌 메뉴 탐색·숫자 입력을 요구하지 않는다.
- 실제 구현 후 카드/조작부 겹침, 잘림, 대비, 터치 영역, 좌우 혼동을 모바일·데스크톱에서 검증한다.

이 문서의 ASCII는 화면 우선순위와 상호작용을 검토하는 도구다. 최종 아트나 구현된 UI 화면이 아니다.
