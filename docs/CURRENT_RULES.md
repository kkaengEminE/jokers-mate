# 현재 게임 규칙 — 2026-10-22

이 문서는 과거 제안과 현행 규칙을 구분하기 위한 현재 기준입니다.

## 진행과 메뉴
메인 메뉴: 시작하기·설정·나가기. 저장 판이 있으면 계속하기 제공. 시작 후 참가금 확인→체스→마지막 판/결과 확인→5장 선택→포커 베팅→한 번의 최종 정산→다음 판 참가 확인. 웹 나가기는 저장 후 메인 메뉴에서 탭을 닫도록 안내하며 강제로 닫지 않습니다.

## 체스
표준 합법 이동·캐슬링·앙파상·승격. 킹은 잡지 않습니다. 승격해도 카드 정체성 유지. 어느 쪽이든5기물이 되면 즉시 종료. 그 수가 체크를 남기면 공격자 승리, 체크가 없으면 무승부. 동시 체크메이트가 우선. 이전 표준 종료 결과가 먼저 나오면 그때 종료합니다.

## 카드와 포커
54장(52+조커2)에서 서로 다른32장 배정. 양쪽 킹은 서로 다른 무늬K, 퀸은 서로 다른 무늬Q. 본인 카드 공개, 상대는 캡처/쇼다운까지 비공개. 캡처 카드 포커 사용 불가. 생존 카드 중5장 선택.

로열플러시부터 하이카드까지 족보→랭크/키커 전체→무늬 전체 순서. 무늬는 ♠>♦>♥>♣. 조커는 자기 패 내부에서 중복 없는 최선의 카드로 치환. 파이브카인드 없음. A2345는5-high.

**정상 게임의 포커는 무승부가 없습니다.** 전체 비교키가 같으면 정렬된 가상 카드5장이 모두 같아야 합니다. 하지만 단일 덱의 서로 겹치지 않는 두 실물 패에는 조커가 합쳐 최대2장이므로 자연 카드가 최소8장 있습니다. 서로 다른8장이 같은 가상5장 안에 들어갈 수 없으므로 완전 동률은 불가능합니다. 동률 입력은 잘못된 카드 배정으로 처리하며 플레이어/조커ID로 임의 승패를 만들지 않습니다. 이전 문서의 포커 동률 분할 제안은 폐기합니다.

## 판돈과 정산 — 최신 직접 설명으로 정정
각자20G, 총40G를 예치합니다. 체스 승자는 이 중15G를 자기 몫으로 확보합니다(30G가 아님). 포커 종료까지 지급하지 않습니다. 나머지25G와 유효 추가 베팅은 포커 승자 몫입니다. 체스 무승부이면 확보몫 없이40G 전체가 포커 팟입니다.

체스승/포커폴드: 시작1000→20예치→15수령→995, 순손실5. 체스패/포커승:1000→20예치→25수령→1005, 순이익5. 두 단계 모두승이면1020. 양쪽 체크해도 포커 패를 비교해 기존 팟을 정산합니다. 최종20 미만이면 실패 엔딩, 상대20 미만이면 승리 엔딩. 새 게임은 양쪽1000부터.

상세 원장·예시·시작/종료 흐름·신규 스토리 제안은 [20 재설계](20_PRODUCT_REDESIGN.md)를 기준으로 합니다. **실행 코드의 split-15-5 경제는 아직 이전30/10 방식이며 이 문서의15확보 방식으로 교체하기 전입니다.** 기존18번 경제 문서는 변경 이력입니다.
