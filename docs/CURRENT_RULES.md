# 현재 설계 기준 — R3 / 2026-10-22

**설계 기준이며, 실행 프로토타입에 아직 전체 반영되지 않았다.**

## 정산
각자20G 예치: 개인 체스15G + 포커5G. 체스에 승자가 있으면 양측의 체스몫30G를 그 승자에게, 양측의 포커몫10G와 유효 추가베팅을 포커승자에게 배당한다. 체스무승부이면30G를 반환하지 않고 전체40G가 포커에 남는다. 포커 종료 후 한 번만 지급한다.

추가베팅 없을 때 체스/포커 모두승:+20, 체스만승:+10, 포커만승:-10, 모두패:-20. 체스무이면 포커승:+20, 패:-20. ‘체스승/포커패15수령’은 이전 assistant 계산 오류이며 폐기한다.

상세 개인별 납부·합산 배당·추가베팅·올인·도주 사례는 [21 정산](21_ECONOMY_CORRECTION.md). 자동 검증 결과는 [23 사례 JSON](23_R3_VERIFICATION.json).

## 체스와 카드
표준 합법 체스. 어느 한쪽이5기물이 되면 종료. 마지막 수가 상대에게 체크를 남기면 공격자승리, 아니면 무승부. 체크메이트 우선. 킹 포획 없음. 승격은 카드정체를 바꾸지 않는다.

단일54장(조커2)에서32장 중복없이 배정. 킹은 서로 다른무늬K, 퀸은 서로 다른무늬Q. 자기카드 공개, 상대는 캡처/쇼다운까지 비공개. 캡처카드는 포커사용불가. 생존카드에서5장 선택.

포커는 족보→랭크/키커→전체무늬순서 ♠>♦>♥>♣로 승자결정. 합법 단일덱 게임에서 포커무승부없음. 조커는 자기패 내부중복없이 최적치환. 파이브카인드없음, A2345는5-high.

## 게임의 시작과 끝
새 게임에서만 프롤로그. 참가금확인→체스→체스결과→포커→정산. 정산 뒤 양쪽20이상이면 계속하기(다음 참가확인)/돌아가기(메인). 활성판 종료는 도주패배 정책, 이미납부액 손실. 세부 저장경계는22번 명세에서 구분한다.

내 잔액20미만이면 상대가 누구든 실패, 이어하기없음, 새 게임은로언부터. 로언 잔액20미만이면 일반승리엔딩. 엔딩보기→돌아가기 후 이어하기는 황제전. 황제 시작금21억. 황제도20미만이면 파산·진엔딩. 진엔딩보기→돌아가기 후 이어하기제거, 새로하기. 영구프로필에황금황제칭호와왕좌초상해금.

상세 흐름과 아직 결정하지 않은 저장정책은 [22 진행 명세](22_CAMPAIGN_FLOW.md). 모든 수정근거와 폐기설명은 [변경대장](CHANGE_REGISTER.md). 디자인은 후속 결정이며 이번에 새 일러스트를 만들지 않았다.
