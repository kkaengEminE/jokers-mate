# Joker’s Mate — 이름 및 향후 확장 메모

2026-10-23 사용자 지시.

## 이름과 주소
- 게임의 공식 표기: **Joker's Mate** (화면에서는 Joker’s Mate).
- 저장소·패키지 슬러그: `jokers-mate`.
- 도메인용 연속 표기: `jokersmate`. 예: `jokersmate.com`, `jokersmate.game`, `play.jokersmate.com`.
- 위 주소는 구매 후보 표기 예시이며 등록 가능 여부나 상표 사용 가능성을 확인한 결과가 아니다. 도메인을 구매·등록하지 않았다. 서브도메인은 확보한 부모 도메인에서 구성한다.
- 새 저장소: https://github.com/kkaengEminE/jokers-mate (기존과 동일하게 비공개).
- 기존 저장소와 Git 이력은 보존한다. 원본 참고문서와 과거 결정 기록의 Gambit 표기는 당시 기록으로 남긴다.
- 기존 브라우저 저장 키는 저장 데이터 보존을 위해 유지한다. 향후 도메인 변경 시 localStorage가 자동 이전되지는 않으므로 저장 내보내기/가져오기 이전 계획이 필요하다.

## 현재 캠페인은 검증용 예시
로언 → 황제 → 진엔딩은 현재 게임성 검증을 위한 예시 구성이다. 상용 출시의 고정 스테이지 구성이나 영구적인 세계관 제약으로 확정하지 않는다.

향후 실제 게임성, 과금 및 콘텐츠 규모를 설계하면 여러 스테이지가 생길 수 있다. 황제는 없어질 수도 있고, 모든 스테이지의 마지막 상대가 될 수도 있다. 지금은 어느 쪽도 확정하지 않는다. 과금 방식·상품·가격·유료 재도전·재화 판매를 승인한 의미도 아니다.

현재 예시를 구현하는 동안에는 문서21~22의 파산·자금·엔딩 규칙을 따른다. 이후 스테이지 구조가 바뀌면 해당 문서와 변경 대장에 새 결정을 기록한다. 상대, 시작 자금, 해금 조건, 엔딩 연결은 교체 가능한 캠페인 데이터로 분리하는 것을 구현 원칙으로 둔다.

일러스트·캐릭터 최종 디자인은 추후 결정한다. 황제 이름 아우렐리온 역시 제안이며 확정된 브랜드 이름 Joker’s Mate와 구분한다.
