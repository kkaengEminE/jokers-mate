# 카드 일기토 — 테스트 대결 구현 안내

작성 기준: 2026-11-03. 최초 플레이 버전은 설정에서 독립 실행한다.

## 시작과 카드 선택

1. 본편의 **설정 → 대결 모드 테스트**를 누른다.
2. 내 카드와 상대 카드 각각의 기물·문양·숫자를 선택한다.
3. 상대 행동과 필살기 시작 게이지를 정한 뒤 **대결 시작**을 누른다.

기물은 폰·나이트·비숍·룩·퀸·킹, 문양은 하트·스페이드·다이아·클럽, 숫자는 2~10·J·Q·K·A다. 조커 1·2도 선택할 수 있다. 기물은 그림과 포즈만 바꾸며, 능력은 [문양 × 숫자 조합식 v1](32_CARD_DUEL_FORMULA.md)으로 고정한다. 조커 1은 ♠5, 조커 2는 ♦7의 기술을 사용한다.

선택 즉시 미리보기와 기본기·콤보·필살기 피해량, 공격 높이, 방어 특성이 갱신된다. 양쪽에 같은 카드를 골라도 된다.

| 상대 행동 | 용도 |
|---|---|
| AI 대결 | 상대가 이동·공격·방어·필살기를 사용하는 실전 연습 |
| 움직이지 않는 상대 | 사거리와 실제 피해 확인 |
| 서서 방어하는 상대 | 상·중단 방어, 하단 공격 확인 |
| 앉아 방어하는 상대 | 하단 방어, 상단 회피, 중단 공격 확인 |

`필살기 100으로 시작`은 양쪽 게이지를 채운다. 기본값은 0이며 효과음은 선택 화면에서 끌 수 있다.

## 조작

| 동작 | 키보드 | 화면 버튼 |
|---|---|---|
| 좌우 이동 | A / D 또는 ← / → 유지 | 좌우 방향 유지 |
| 앉기 | S 또는 ↓ 유지 | 아래 방향 유지 |
| 기본기 | J | 기본기 이름 버튼 |
| 콤보 | K | 콤보 |
| 서서 방어 | L 유지 | 방어 유지 |
| 하단 방어 | S + L 유지 | 아래 + 방어 동시 유지 |
| 하단 쓸기 | S + J | 아래 유지 중 기본기 |
| 필살기 | I, 게이지 100 필요 | 필살기 |
| 일시정지 | Esc | 타이머 아래 Ⅱ |

터치는 이동과 공격, 앉기와 방어를 동시에 누를 수 있다. 방향·방어 버튼 밖으로 손가락을 옮기거나 떼면 해제된다. 방어 중에는 공격하지 않는다. 서서 상·중단을 막고, 앉아서 하단을 막는다. 상단 공격은 앉은 상대를 지나가고, 중단 공격은 앉은 상대에게 명중한다.

## 대결과 결과

- 3·2·1 이후 60초 단판. 양쪽 체력 100, 자연 회복 없음.
- 체력 바는 금색 테두리 안의 녹색 막대이며, 50 이하에서 황색, 20 이하에서 적색으로 변한다. 손실 체력은 잠깐 붉은 잔상으로 표시한다.
- 체력 아래 보라색 4칸 막대가 필살기 게이지다. 100이면 금색으로 강조한다.
- 실제 타격 시각에 피해·경직·밀림을 계산한다. 그림이나 브라우저 프레임 수로 피해를 계산하지 않는다.
- 일반 공격의 방어 피해는 0, 필살기 방어 피해는 원래 피해의 20%다. 방어 피해로는 체력 1 미만이 되지 않는다.
- 일반기·콤보의 첫 명중에 공격자 게이지 +12, 한 기술을 방어하면 수비자 +8, 한 기술에 맞으면 수비자 +5다. 연속 타격 수만큼 반복 지급하지 않는다.
- 필살기 발동 시 게이지 100을 소비한다. 공격 중 피격되면 남은 타격을 취소하고 사용한 게이지를 돌려주지 않는다.
- 체력 0이면 KO. 시간 종료는 표시 반올림 전 체력으로 비교한다. 동시 KO·동일 체력은 무승부다.
- 결과에는 남은 체력, 준 피해, 명중·방어 횟수, 필살기 횟수와 승패를 결정한 마지막 타격 또는 시간 종료 이유가 나온다. **경기 상세**에서 시간순 사건을 펼칠 수 있다.
- 결과에서 같은 카드로 재대결, 카드 재선택, 설정 복귀가 가능하다.

예: ♥9의 정권은 6, 발차기 콤보는 5+7, 삼단 연환각은 8+8+10이다. 필살기를 모두 맞으면 26, 전부 적절한 자세로 막으면 5.2, 서서 계속 막으면 마지막 하단이 명중해 총 13.2 피해다.

브라우저 포커스 상실·탭 숨김·화면 회전 시 대결을 정지하고 눌린 입력을 해제한다. `계속하기`는 정지한 시점에서 즉시 재개한다. 종료는 확인 화면을 거쳐 카드 선택 또는 설정으로 돌아간다.

## 이미지와 모션

기존 `public/art/checards-v1.png`를 캐릭터 참고 이미지로 사용하여 이미지 생성 도구로 제작했다. 배경과 스프라이트는 외부 URL 없이 저장소에서 제공한다.

| 파일 | 규격 | 내용 |
|---|---|---|
| `public/art/duel/garden.png` | 1672×941, RGB PNG | 빅토리아 왕실 정원의 측면 결투 회랑, 수채·잉크 삽화 |
| `public/art/duel/fighters.png` | 1448×1086, 투명 RGBA PNG | 181×181 셀, 8열 × 6행, 총 48개 핵심 포즈 |

스프라이트 행은 위부터 폰·나이트·비숍·룩·퀸·킹이다. 열은 왼쪽부터 대기/서서 방어, 걷기, 정권, 상단 차기, 중단 차기, 앉기/하단 방어, 피격, KO다. SVG로 해당 셀을 잘라 표시하고, 상대는 좌우 반전한다. 문양과 숫자는 게임 데이터로 따로 올려 읽을 수 있게 한다.

이동은 대기·걸음 포즈를 교차하고, 공격은 기술의 준비·타격·회복 시각에 포즈를 바꾼다. 방어 호, 명중 섬광, 피해 숫자, 필살기 이름, KO·승패 화면과 간단한 합성 효과음을 연결했다. 모션 감소 설정에서는 CSS 효과를 줄이되 타격·방어·피격 포즈는 유지한다.

현재 그림은 여덟 핵심 포즈를 공유한다. 하단 쓸기·팔꿈치·찌르기 등의 개별 연결 동작, 높이별 피격, 기물별 부속품 흔들림, 별도 승리 모션은 [전체 모션 설계](34_CARD_DUEL_MOTIONS.md)의 후속 제작 대상이다. 승자는 현재 대기 포즈와 금색 광채로 표시한다.

## 본편과 데이터

테스트 대결은 본편 금화·체스·포커·캠페인 기록을 변경하지 않는다. 본편 자동 진행은 모달이 열려 있는 동안 멈춘다. 마지막으로 고른 양쪽 카드만 `jokers-mate-duel-lab-v1`에 저장하며, 저장을 사용할 수 없어도 기본 카드로 실행된다. 진행 중 대결과 결과는 새로고침 후 복원하지 않는다.

정산 화면에서 실제 쇼다운 카드로 신청하고 상대가 수락·거절하는 흐름, 캠페인 일기토 기록은 [전체 대결 설계](33_CARD_DUEL_COMBAT.md)에 남아 있다. 이 테스트 모드는 상대 카드까지 자유롭게 선택한다.
