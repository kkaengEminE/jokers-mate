# 18 · 승인된 경제: 체스15 / 포커5

2026-10-21 사용자 명시 승인: “분리 팟 +20G 보장 폐지”, “체스를15 포커를5로 해줘.” 새 판에 적용하며 이전 경제 제안을 대체한다.

각 판 시작에 각자20G 예치: 체스15G, 포커5G. 체스 팟30G는 승자에게 배당하고 무승부이면15씩 반환한다. 배당은 포커 종료까지 잠기므로 추가 베팅에 재사용할 수 없다. 포커 기본 팟은10G. 체크도 참가금은 걸려 있으며 폴드하면 잃는다. 마지막에 두 단계 배당을 합산하고 다음 판은 새 체스로 시작한다. 최종20G 보호 보정은 없다. 한쪽이20G 미만이면 다음 판 참가 불가.

## 계산
B_i=시작잔액, C_i=체스예치15를 포함한 누적투입(20≤C_i≤B_i).
m=min(C_w,C_b), 반환 R_i=C_i-m, 포커 팟 P=2(m-15).
체스 배당 A_i=승30/무15/패0. 포커 배당 W_i=승P/무P÷2/패0.
F_i=B_i-C_i+R_i+A_i+W_i. 합계2000 보존. 별도 보호금 없음.

원장의 committed는 체스 예치를 포함한다. 화면의 포커 투입·레이즈 입력은15를 뺀 금액이며, 입력 시 다시15를 더한다. 추가 베팅 가능액은 B_i-C_i다. 미대응 베팅 반환은 포커만 대상으로 하며 체스 배당을 재매칭하지 않는다. 최소 추가 베팅/정상 레이즈20G는 유지한다.

| 체스 / 포커 | 추가 베팅 없는 내 순손익 |
|---|---:|
|승 / 승|+20|
|승 / 패 또는 폴드|+10|
|패 / 승|-10|
|패 / 패|-20|
|무 / 승|+5|
|무 / 패|-5|

체스만 계속 이기고 포커를 폴드해도+10G가 남는다. 이는 사용자 지정 가중치의 의도된 결과로, 포커 회피를 막는 설계는 아니다. 시작20에서 체스무/포커패이면15가 남고 참가 불가다. 체스승/포커패이면30이 남는 것은 보호금이 아니라 체스 배당30 때문이다.

## 호환 및 검증
새 판은 economy=split-15-5로 식별. 기존 economy 필드 없는 v2 저장은 기존20G포커 참가금/체스승자20보호로 끝낸다. 다음 판 생성 시 새 규칙으로 전환한다. 저장 복원은 해당 원장 규칙으로 정산을 재계산하여 변조/혼합을 거부한다. 기록 내보내기에 경제 식별자와 체스 배당을 포함한다.

84개 테스트 통과: 8개 단계별 승패 조합, 초과 베팅 반환, 저잔액, 648개 잔액·투입·승자 조합과 좌우 대칭, 구버전 복원 및 새 판 전환 등을 포함한다. 기존 체스·조커·베팅 테스트도 유지한다.
