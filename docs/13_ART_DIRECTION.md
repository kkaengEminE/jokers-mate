# 13 · 프로토타입 미술 방향

짙은 정원색, 크림색 카드, 금빛 선과 세리프 제목으로 빅토리아 왕실 정원·아르누보의 분위기를 구현한다. 체스판과 카드의 가독성을 우선하고 금고·캡처함을 대칭으로 구성한다.

현재 기물은 시스템 Unicode 체스 글리프이며 의인화 캐릭터의 최종 아트가 아니다. 테이블·카드 뒷면·장식·마차와 깃발은 코드와 CSS로 표현한다. 별도 이미지 자산이나 Disney 기반 이미지는 사용하지 않았다. 외부 폰트는 선택적이며 로딩 실패 시 시스템 서체로 대체한다.

후속 비교 대상은 polished pixel art, Art Nouveau illustration, Victorian royal garden 2D의 세 방향이다. 실제 캐릭터 원화, 체스 모자를 쓴 카드 병사, 완성된 마차·시종 애니메이션, 음향은 별도 미술 단계에서 다룬다. 현재 프로토타입 방향을 최종 아트 승인으로 간주하지 않는다.
