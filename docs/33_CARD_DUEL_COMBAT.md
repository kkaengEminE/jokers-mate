# 카드 일기토 — 화면·조작·전투·연출 설계서 v0.3

작성 기준: 2026-11-03. 상태: 전체 기능의 목표 설계. 설정에서 실행하는 테스트 대결을 먼저 구현했다.

이 문서는 화면에 무엇을 배치하고, 어떤 키를 누르면 무엇이 일어나며, 어떤 수치와 연출로 경기를 진행·종료하는지 정한다. 카드 능력은 [기물 × 문양 × 숫자 조합식 v2](36_CARD_DUEL_FORMULA_V2.md)를 따른다. 현재 구현 범위와 목표 설계의 차이는 [테스트 대결 구현 안내](35_CARD_DUEL_TEST_MODE.md)를 참고한다. 아래 본편 신청·저장·세부 연출까지 모두 구현했다는 뜻은 아니다. 2026-11-04 업데이트: 현재 KO는 전체 화면을 가리지 않고 3초간 피격·쓰러짐을 보여 준 뒤 결과를 연다. 아래 과거 1600ms 결과 제안보다 이 규칙이 우선한다.

## 1. 경기 기본값

| 항목 | 규격 |
|---|---|
| 형식 | 옆에서 보는 2D 실시간 격투, 플레이어 1명 대 AI 1명 |
| 참가자 | 이번 포커 쇼다운에 제출한 카드 다섯 장 중 각자 한 장 |
| 라운드 | 1라운드, 제한 시간 60초 |
| 체력 | 양쪽 100. 자연 회복 없음 |
| 필살기 게이지 | 양쪽 0에서 시작, 최대 100, 발동 비용 100 |
| 승패 | 체력 0이면 KO. 시간 종료 시 남은 실제 체력이 높은 쪽 승리. 동시 KO·동일 체력은 무승부 |
| 신청 | 완료한 대국 하나당 한 번. 거절·수락 후 취소·중도 종료도 신청 사용으로 기록 |
| 정산 | 일기토는 추가 참가비·금화 배당 없음. 본편의 체스·포커 정산은 먼저 확정 |
| 화면 | 기준 1280×720. 좁은 가로·세로 화면에서는 HUD와 조작부를 재배치 |

## 2. 체스가 끝난 뒤 연결되는 순서

기존 본편의 순서는 **체스 → 포커 → 정산**이다. 처음 요청한 ‘카드 게임이 끝나고 신청’에 맞춰 일기토 제안은 정산 이후에 배치한다.

```text
체스 종료
  └─ 체스 결과 [포커로 계속]
       └─ 패 다섯 장 선택 → 포커 베팅 → 쇼다운 → 금화 정산 확정
            └─ 최종 정산
                 ├─ [다음 대국 준비] → 기존 다음 대국
                 └─ [카드 일기토 제안]
                      └─ 내 카드 선택 [이 카드로 제안]
                           └─ 상대 답변
                                ├─ 거절 → [정산으로 돌아가기]
                                └─ 수락 → 양쪽 카드 소개 [대결 시작]
                                              └─ 입장 → 3·2·1·시작 → 60초 대결
                                                   └─ KO / 시간 종료 / 무승부
                                                        └─ 일기토 결과 [정산으로 돌아가기]
```

### 화면별 문구와 버튼

| 화면 | 표시할 내용 | 버튼과 실제 동작 |
|---|---|---|
| 체스 결과 | 기존 승패·종료 사유. 첫 안내에만 “포커가 끝나면 카드 한 장으로 일기토를 제안할 수 있습니다.” | `포커로 계속`: 기존 포커 패 선택으로 이동 |
| 최종 정산 | 기존 금고와 순손익 아래 별도 영역. 제목 `카드 일기토`, 설명 `이번에 낸 카드 한 장으로 상대에게 결투를 제안합니다.` | `카드 일기토 제안`: 카드 선택. 기존 `다음 대국 준비`는 일기토를 건너뛰고 진행 |
| 내 카드 선택 | 내 패 다섯 장, 선택한 병사 미리보기, 네 기술과 피해, 문양 특성 | `♥9로 일기토 제안`: 신청 확정. `돌아가기`: 정산 복귀, 신청 미소모 |
| 답변 대기 | 내 카드와 상대 초상. `로언에게 일기토를 제안했습니다.` | 1.2초 뒤 답변 표시. 신청 버튼 중복 클릭 금지. Enter/탭으로 대기 연출만 생략 가능 |
| 상대 거절 | `로언이 일기토를 거절했습니다.` 대사 `오늘은 여기까지다. 다음 대국에서 만나자.` | `정산으로 돌아가기`: 복귀. 같은 판에 다시 신청할 수 없음 |
| 상대 수락 / VS | `제안을 받아들였다.` 내 카드와 상대 카드, 네 기술 요약과 조작 안내 | `대결 시작`: 경기장 입장. `취소하고 돌아가기`: 신청 사용을 유지하고 정산 복귀 |
| 경기 종료 | 일기토 승패, 사용 카드, 남은 체력, 승패 결정 사건, 대전 통계 | `정산으로 돌아가기`: 원래 정산 복귀. `경기 상세`: 사건 기록 펼치기 |

- 일기토 제안창을 자동으로 띄우지 않는다. 정산을 읽은 뒤 사용자가 버튼을 눌러 연다.
- 포커 폴드·대국 포기로 끝난 판은 제안 대상에서 제외한다. 해당 영역에 `쇼다운까지 마친 판에서 일기토를 제안할 수 있습니다.`를 표시한다. 상대 비공개 패를 공개하지 않는다.
- 최종 보스 승리·캠페인 실패 판에서도 정상 쇼다운이면 일기토를 할 수 있다. 이후 정산에서 기존 `엔딩 보기` 또는 `실패 화면 보기`로 진행한다.
- 이미 신청한 판의 정산에는 `일기토: 승리 / 패배 / 무승부 / 거절 / 취소 / 중단`을 표시한다. 완료된 경기의 결과 다시 보기는 가능하지만 재대결 버튼은 두지 않는다.
- 메인 화면으로 돌아가도 현재 판의 신청 여부는 유지한다. 다음 대국에 진입하면 이전 판의 미사용 신청 기회는 종료된다.

### 수락과 상대 카드 선택

첫 유효 신청은 반드시 수락한다. 이후 로언은 80%, 황제는 60% 확률로 수락하는 설계안이다. 이 확률은 상대의 답변에만 쓰이며 카드 능력에는 랜덤 배정이 없다.

신청 확정 시 카드·수락 결과·상대 카드 선택을 함께 저장한 뒤 답변을 표시한다. 저장 실패 시 신청을 소비하지 않고 선택 화면에 `저장하지 못했습니다. 다시 시도해 주세요.`를 표시한다. 저장 후 새로고침하면 같은 답변과 카드를 보여 준다.

상대는 자기 패 다섯 장에서 균등 확률로 한 장을 선택한다. 내 카드에 맞춰 능력을 바꾸거나 패 밖의 카드를 가져오지 않는다. 상대 카드가 공개된 뒤 내 카드는 변경할 수 없다.

## 3. 카드 선택과 대결 소개 화면

### 내 카드 선택

기준 폭 960px의 중앙 패널, 높이는 화면의 90% 이하. 작은 화면에서는 내용만 세로 스크롤하고 하단 버튼은 고정한다.

- 위: `일기토에 나설 카드 한 장을 고르세요`.
- 가운데: 다섯 카드. 1280px 화면에서 카드 각각 128×176px, 간격 16px. 좁은 화면은 가로 스크롤하며 스크롤 가능 표시를 둔다.
- 최초에는 선택 없음. 신청 버튼 비활성. 카드 선택 시 금색 2px 테두리·체크 표시·8px 들림으로 선택 상태를 표현한다.
- 아래: 선택한 카드 이름, `체력 100`, 문양 특성, 기술 네 개와 피해량. 필살기에는 `게이지 100 필요`.
- ♥9 표기 예: `정권 6 / 발차기 5+7 / 상단 방어 / 삼단 연환각 8+8+10`.
- 도움말 `공통 조작`: `S+J 하단 쓸기 4`, `L 방어`, `S+L 하단 방어`.
- 돌아가기는 신청 전까지만 무료 취소. 카드 선택에 제한 시간은 없다.

### 수락 후 VS 소개

좌측 내 카드, 우측 상대 카드, 중앙 `VS`. 병사의 모자는 이번 체스 종료 시 역할을 유지하고 몸통에 숫자·문양을 표시한다. 기물별 기본기와 연계 보정은 v2 조합식을 따른다. 자유 테스트에서는 진영을 선택하며 상대는 항상 반대색이다.

각 병사 아래에 카드 이름, 기본기·콤보·필살기의 이름과 피해량을 적는다. 하단에는 `A/D 이동 · S 앉기 · J 기본기 · K 콤보 · L 방어 · I 필살기` 한 줄과 `대결 시작` 버튼을 둔다. 조작 안내는 사용자가 읽고 시작할 때까지 유지한다.

## 4. 배경·캐릭터·화면 배치

### 배경

무대 이름은 `왕실 정원 · 결투 회랑`.

- 원경: 옅은 황토색 궁전과 하늘, 낮은 대비로 처리한다.
- 중경: 짙은 올리브 생울타리와 석조 아치. 중앙은 병사와 겹치는 복잡한 장식을 비운다.
- 바닥: 가로로 이어지는 크림색 석판, 양 끝은 낮은 문양 기둥. 장외 낙하 없음.
- 채색: 기존 체카드와 같은 잉크 외곽선·해칭·누런 종이·수채 질감. 실제 전투 무대는 고정 시점이며 공격 때 카메라 확대를 반복하지 않는다.
- 캐릭터: 카드 몸통·얼굴·팔다리·체스 모자를 유지. 양쪽 옷깃과 발밑 표식에 `나`와 `상대`를 표시해 같은 카드 문양도 구별한다.
- 병사가 겹쳐도 읽히도록 상대 윤곽은 짙은 잉크색, 내 윤곽은 크림색 보조선. 기술 이펙트는 몸통의 카드 숫자를 오래 가리지 않는다.

### 1280×720 기준 구성

```text
┌────────────────────────────────────────────────────────────┐
│ [♥9] 나  [████████ 체력 100/100]   60   [체력 100/100 █████] 로언 [♣K] │
│          [──── 필살 0/100 ────]        [──── 필살 0/100 ────]       │
│                                                            │
│       궁전 · 생울타리 · 석조 회랑                            │
│                                                            │
│              내 카드 병사          상대 카드 병사            │
│────────────────────── 석판 바닥 ────────────────────────────│
│ [←] [→]                      기술 표시        [기본 J] [콤보 K] │
```

좌표 원점은 좌측 상단. 기준값:

| 영역 | 위치·크기 |
|---|---|
| HUD | y=0~104, 반투명 짙은 녹색 배경 |
| 내 카드 초상 | x=24, y=16, 64×80 |
| 내 체력바 | x=104, y=28, 416×28 |
| 상대 체력바 | x=760, y=28, 416×28 |
| 상대 카드 초상 | x=1192, y=16, 64×80 |
| 시간 표시 | 화면 중앙 x=640 기준, y=24, 80×64 장식 프레임 |
| 필살기 게이지 | 각 체력바 아래 y=78, 416×10 |
| 병사 발 기준선 | y=520. 기본 서 있는 키 220px |
| 경기장 | y=104~540 |
| 조작부 | y=540~720. 이동 좌측, 네 기술 우측, 가운데 현재 기술명 |

### 작은 화면

- 가로 화면 높이 480px 미만: HUD 높이 64px, 병사 높이 140px 기준, 조작 버튼 56px. HUD와 조작부를 각각 재배치해 전체 화면을 단순 축소하지 않는다.
- 세로 화면: 위 HUD → 폭에 맞춘 16:9 경기장 → 아래 이동·기술 조작부. 글자 최소 13px, 버튼 최소 48px, 안전 여백 8px.
- 조작 버튼은 병사 몸과 겹치지 않는 별도 영역에 둔다. 모바일 브라우저 주소창 높이가 바뀌어도 하단 버튼이 잘리지 않게 실제 표시 높이를 사용한다.
- 체력·시간·버튼은 항상 표시한다. 설명 패널만 일시정지 중 열고 스크롤한다.

## 5. 체력바와 필살기 게이지 모양

### 체력바

- 가로로 긴 **양 끝이 비스듬한 금색 프레임**. 테두리 2px, 내부는 어두운 녹색.
- 20 체력마다 얇은 세로선: 총 다섯 구간. 현재 체력은 막대 아래 `74 / 100` 숫자로 병기한다.
- 내 바는 왼쪽 초상 쪽에 고정하고 오른쪽 끝부터 줄어든다. 상대 바는 오른쪽 초상 쪽에 고정하고 왼쪽 끝부터 줄어든다.
- 체력 50 초과: 올리브 녹색 `#81A86B`. 20 초과~50 이하: 황금색 `#D4AE58`. 0 초과~20 이하: 탁한 적색 `#C65B50`. 색과 숫자를 함께 사용한다.
- 피해 확정 순간 현재 바와 숫자를 즉시 줄인다. 줄어든 부분에는 붉은 잔상이 180ms 남았다가 280ms 동안 현재 길이로 따라 줄어든다. 추가 피격 시 실제 체력 표시를 기다리게 하지 않는다.
- 체력이 0보다 조금이라도 남으면 숫자는 정수 올림으로 표시한다. 0일 때만 KO. 결과 상세에는 소수 둘째 자리까지 표시한다.

### 필살기 게이지

- 체력바 아래 **네 칸으로 구분된 얇은 가로 막대**, 한 칸당 25.
- 채움색은 탁한 자주색 `#9476A4`. 일반 상태는 `필살 42/100`.
- 100이면 막대 테두리가 금색으로 바뀌고 `필살기 준비`를 표시한다. I 버튼도 금색 테두리와 준비 표시. 지속적인 점멸은 쓰지 않는다.
- 필살기 시작 시 즉시 0으로 바뀐다. 해당 기술의 잔여 시간은 버튼을 덮는 어두운 부채꼴로 표시한다.
- 별도 스태미나·마나·방어 게이지는 없다.

## 6. 키와 버튼 — 실제 입력 규칙

| 행동 | 키보드 | 화면 버튼 | 동작 |
|---|---|---|---|
| 왼쪽 이동 | A 또는 ← 유지 | `←` 유지 | 초당 1.8 거리 × 문양 이동 배율 |
| 오른쪽 이동 | D 또는 → 유지 | `→` 유지 | 같은 속도로 이동 |
| 앉기 | S 또는 ↓ 유지 | `앉기` 유지 | 이동을 멈추고 앉기. 상단은 회피하지만 중·하단은 무방비 |
| 기본 공격 | J 한 번 | 기본기 버튼 한 번 | 숫자별 기본기 한 번 실행 |
| 공통 하단 쓸기 | S+J 또는 ↓+J | 앉기 유지 + 기본기 | 모든 카드 공통, 하단 피해 4에 문양 보정 |
| 콤보 | K 한 번 | 콤보 버튼 한 번 | 정해진 연속 동작 전체를 실행. 매 타마다 버튼을 누르지 않음 |
| **서서 방어** | **L 유지** | **방어 버튼 유지** | 상·중단 방어. 하단은 피격 |
| **하단 방어** | **S+L 또는 ↓+L 유지** | **앉기 + 방어 유지** | 하단 방어, 상단 회피, 중단 피격 |
| 필살기 | I 한 번 | 필살기 버튼 한 번 | 게이지 100일 때 사용 |
| 일시정지 | Esc | 우측 상단 `Ⅱ` | 양쪽 전투·타이머 정지 |

- 방어는 토글이 아니라 누르고 있는 동안만 유지한다. 키나 손가락을 떼면 해제된다.
- 행동 가능한 상태에서 방어 입력은 다음 전투 갱신부터 적용한다. 공격·회복·피격 중이면 해당 상태가 끝나야 방어 가능하다.
- 서서 방어하며 이동은 정상 속도의 50%. 앉기·앉아 방어 중 이동은 0.
- 방어를 유지한 채 공격 버튼을 누르면 방어가 우선한다. 공격하려면 방어를 놓는다.
- 공격 버튼을 길게 누른다고 자동 연타하지 않는다. 한 번의 새 누름에 한 번 발동한다.
- 왼쪽·오른쪽을 동시에 누르면 이동 0. 여러 공격 버튼을 동시에 누르면 J → K → I 중 하나를 선택한다.
- 행동 종료 전 마지막 100ms에 누른 공격 하나만 예약한다. 게이지 부족한 필살기는 예약·소모되지 않고 `게이지 부족`을 600ms 표시한다.
- 터치는 각각의 손가락을 구별해 이동+공격, 앉기+방어를 함께 처리한다. 손가락이 버튼 밖으로 나가거나 터치가 취소되면 해당 유지 입력을 해제한다.
- 대결 중 키 입력은 게임 조작에 사용한다. 카드 선택·결과의 버튼에 포커스가 있으면 Enter/Space는 그 버튼을 누르는 표준 동작이다.

### 방어 결과표

| 상대 타격 | L만 유지 | S+L 유지 | S만 유지 |
|---|---|---|---|
| 상단 | 방어 | 회피 | 회피 |
| 중단 | 방어 | 피격 | 피격 |
| 하단 | 피격 | 방어 | 피격 |

기본기·콤보를 방어하면 피해 0. 필살기 방어 피해는 계산된 타격 피해의 20%이며 체력이 1 아래로 내려가지 않는다. 회피는 피해·방어 게이지 획득 모두 0이다.

## 7. 어떤 기술이 몇 피해를 주는가

숫자별 기술 이름·개별 타격·사거리는 조합식 문서가 원본이다. 다음은 **문양 보정 전, 전 타격 명중 시**의 요약이다. 콤보를 일부만 맞히면 해당 타격 피해만 합산한다.

| 숫자 | 기본기 / 피해 | 콤보 / 타격별 피해 | 필살기 / 타격별 피해 |
|---|---|---|---|
| 2 | 빠른 잽 / 4 | 쌍권 / 4+5=9 | 쌍성권 / 10+12=22 |
| 3 | 하단 차기 / 5 | 쓸어차기 / 4+6=10 | 지면 연각 / 10+12=22 |
| 4 | 팔꿈치 / 8 | 팔꿈치 연격 / 6+6=12 | 파쇄 연격 / 12+12=24 |
| 5 | 정권 / 6 | 교차 연격 / 5+5=10 | 교차 섬격 / 11+11=22 |
| 6 | 긴 찌르기 / 5 | 연속 찌르기 / 4+6=10 | 관통 연권 / 10+12=22 |
| 7 | 빠른 잽 / 4 | 삼연권 / 3+3+4=10 | 삼연 쇄권 / 7+7+8=22 |
| 8 | 팔꿈치 / 8 | 무릎 연격 / 7+6=13 | 철산 연격 / 14+12=26 |
| 9 | 정권 / 6 | 발차기 콤보 / 5+7=12 | 삼단 연환각 / 8+8+10=26 |
| 10 | 하단 차기 / 5 | 이단 쓸기 / 5+6=11 | 지면 파쇄각 / 11+13=24 |
| J | 빠른 잽 / 4 | 잔상 연권 / 3+3+3=9 | 잔상 사연권 / 5+5+6+6=22 |
| Q | 긴 찌르기 / 5 | 교차 차기 / 5+5=10 | 반월 교차각 / 7+8+8=23 |
| K | 팔꿈치 / 8 | 왕관 강타 / 14 | 왕관 파쇄권 / 28 |
| A | 정권 / 6 | 정권 연계 / 5+5=10 | 일섬 연권 / 11+11=22 |

문양별 피해 배율은 ♥×1.00, ♠×0.95, ♦×0.95, ♣×1.10. 예: ♣K 왕관 강타는 14×1.10=15.4, ♥9 필살기는 합계 26. 조커 J1은 ♠5, J2는 ♦7 구성이다.

### ♥9의 키별 수치와 타격 시점

| 키 | 기술 | 타격 / 피해 | 첫 타격 | 후속 타격 | 마지막 타격 후 조작 불가 |
|---|---|---|---|---|---|
| J | 정권 | 중 / 6 | 120ms | 없음 | 220ms |
| S+J | 하단 쓸기 | 하 / 4 | 260ms | 없음 | 400ms |
| K | 발차기 콤보 | 상 5 → 중 7 | 240ms | 시작 후 480ms | 420ms |
| L | 서서 방어 | 성공 시 기본기·콤보 피해 0 | 행동 가능 상태면 다음 갱신 | 유지하는 동안 적용 | 상단 방어 경직 90ms, 중단 120ms |
| S+L | 하단 방어 | 성공 시 기본기·콤보 피해 0 | 행동 가능 상태면 다음 갱신 | 유지하는 동안 적용 | 하단 방어 경직 120ms |
| I | 홍련 · 삼단 연환각 | 상 8 → 중 8 → 하 10 | 350ms | 시작 후 650ms / 950ms | 650ms |

위 타격 시간은 기술의 전투 시간이 흐른 값이며, 별도 필살기 소개 연출·일시정지·명중 정지 시간은 포함하지 않는다. ♥9 필살기를 세 번 모두 방어하면 1.6+1.6+2=5.2 피해다. 끝까지 서서 방어하면 마지막 하단 10은 직접 피격하므로 1.6+1.6+10=13.2 피해다(남은 체력이 충분할 때).

### 게이지 획득

| 사건 | 획득 |
|---|---:|
| 기본기·하단 쓸기·콤보 한 번에서 첫 직접 명중 | 시전자 +12 |
| 상대 기술 한 번에서 첫 성공한 방어 | 방어자 +8 |
| 상대 기술 한 번에서 첫 직접 피격 | 피격자 +5 |

각 항목은 기술 실행 한 번마다 한 번만 지급한다. 같은 연속기를 일부 방어하고 일부 맞으면 +8과 +5를 각각 한 번 얻는다. 헛침·상단 회피에는 지급하지 않는다. 필살기 시전자는 자기 필살기로 게이지를 얻지 않으며, 상대는 방어·피격분을 얻는다.

## 8. 맞았을 때·막았을 때의 효과

모든 시간은 연출 기준값이다. 피해는 판정 순간 한 번만 확정한다. 실제 잔여 체력보다 큰 피해는 체력 0까지만 차감하고, 떠오르는 숫자와 통계도 실제 차감량을 사용한다.

| 사건 | 캐릭터 동작 | 화면 효과 | 숫자·소리 |
|---|---|---|---|
| 정권·잽·찌르기 명중 | 맞은 부위가 뒤로 젖혀지고 160ms 피격 동작 | 접점에 크림색 잉크 별 180ms, 피격자 몸통에 붉은 색조 80ms | `−6`처럼 실제 피해가 20px 올라가며 650ms에 사라짐. 짧은 타격음 |
| 하단 차기·쓸기 명중 | 다리가 굽혀지고 하체가 흔들림, 피격 160ms | 발목 높이의 작은 별과 석판 먼지 180ms | 피해 숫자와 낮은 타격음 |
| 콤보 명중 | 각 타격마다 해당 부위 피격 | 타격마다 작은 별. 마지막 타격은 별을 1.3배 확대 | 타격별 피해 표시, 공격자 옆 `2 HIT` 등 명중 수 표시 |
| 방어 성공 | 팔을 올리거나 앉아 막는 자세 | 앞쪽에 청회색 반원 방패 240ms | `방어` 350ms, 금속성 짧은 막힘음. 기본기·콤보는 피해 숫자 없음 |
| 필살기 방어 | 방어 자세 유지 | 방패 반원 + 작은 금빛 파편 | `방어 −1.6`처럼 실제 방어 피해 표시 |
| 상단 회피 | 앉은 자세 유지 | 머리 위로 타격 궤적만 지나감 | `회피` 350ms, 바람 소리. 피해 숫자 없음 |
| 사거리 밖 | 시전자 기술 동작은 끝까지 진행 | 접촉 별·피격 색조 없음 | 시전자 옆 `사거리 밖` 350ms, 휘두르는 소리만 |

### 짧은 명중 정지

기본기·콤보·필살기 중간 타격이 명중하면 양쪽 병사의 동작을 45ms 멈춘다. 필살기 마지막 타격 명중은 90ms, 방어 성공은 30ms. 같은 순간 여러 사건이면 가장 긴 한 번만 적용한다.

이 정지 동안 양쪽 전투 시간과 60초 타이머도 함께 멈춘다. 숫자·별·잔상만 표시된다. 정지 종료 후 남은 동작을 이어 간다. 기술별 공격 순서나 피해가 추가되지 않는다.

### 필살기 시작 연출

- I 입력이 유효하면 게이지 100을 즉시 소모한다.
- 배경만 25% 어두워지고 카드 문양과 `홍련 · 삼단 연환각` 같은 기술명이 가로 붓자국 위에 200ms 나타난다. HUD는 가리지 않는다.
- 이 200ms 동안 양쪽 전투·타이머는 정지한다. 이후 배경을 복원하며 원래 기술 준비 시간부터 시작한다.
- 하트는 탁한 붉은 호, 스페이드는 먹색·금색 칼선, 다이아는 청회색 종이 파편, 클럽은 올리브색 넓은 붓선을 사용한다. 문양 이펙트로 별도 추가 타격을 만들지 않는다.
- 필살기 마지막 명중 때 화면 흔들림 최대 3px·120ms. 일반 공격에는 화면 흔들림 없음.
- 모션 감소 설정은 화면 흔들림·색조 번쩍임·피해 숫자 이동을 없애고 고정 텍스트로 대체한다. 피해·경직·양쪽 전투 정지 시간은 같게 유지한다.

## 9. 대결 시작 연출과 타이머

`대결 시작`을 누른 후:

| 구간 | 표시와 동작 |
|---|---|
| 0~250ms | VS 화면이 종이처럼 좌우로 열리며 경기장 표시 |
| 250~850ms | 두 카드 병사가 지정된 시작 위치에 걸어 들어와 정지. 체력 100·게이지 0 표시 |
| 850~1850ms | 중앙 `3` |
| 1850~2850ms | 중앙 `2` |
| 2850~3850ms | 중앙 `1` |
| 3850ms | `시작!` 표시와 동시에 조작·60초 타이머 활성화. 시작 글자는 400ms 후 사라짐 |

입장 연출은 Enter/화면 탭으로 생략할 수 있지만 3·2·1은 유지한다. 시작 전에 눌렀던 공격 입력은 지우며, 유지 중인 이동·방어는 시작 시점부터 적용한다.

시간은 정수 초로 올림 표시한다. 10초부터 시간 숫자를 황금색, 5초부터 붉은색으로 바꾸고 5·4·3·2·1에서 작은 종소리를 낸다. 전체 화면 점멸은 없다.

타이머는 대결이 실제 진행되는 동안만 감소한다. 입장·필살기 소개·명중 정지·일시정지 동안은 멈춘다. 따라서 제한 표시는 60초지만 연출을 포함한 실제 소요 시간은 더 길 수 있다.

## 10. 전투 판정과 입력 상태

- 기본 이동 속도는 초당 1.8에 문양 배율을 곱한다. 경기장 길이 8.0, 병사 몸 너비 0.5, 시작 중심 위치 2.4 / 5.6.
- 사거리는 마주 보는 몸 앞쪽 사이 빈 거리다. 양쪽은 서로 통과하지 못하며, 자동으로 상대를 바라본다.
- 공격 중 자유 이동은 없다. 앉아 시작한 콤보·필살기는 서서 실행한다. 하단 쓸기는 타격까지 앉은 자세다.
- 준비 → 개별 타격 → 회복 순서. 각 타격 시각마다 거리와 방어 자세를 다시 확인한다.
- 공격자가 피격되면 아직 나가지 않은 후속 타격을 취소하고 160ms 피격 상태로 전환한다. 필살기 비용은 환불하지 않는다.
- 같은 시각의 공격은 서로 피해를 적용하기 전 상태에서 판정해 동시 명중 가능. 그 시각의 피해를 모두 적용한 뒤 KO 판정.
- 기본기·하단 쓸기 명중 시 뒤로 0.10, 방어 시 0.05 이동. 콤보·필살기는 명중·방어 타격당 0.03 이동. 벽이면 경계에서 멈추며 추가 피해 없음.
- 거리 밖으로 밀려나면 후속타는 빗나갈 수 있다. 명중 확률 주사위는 없다.
- 제한 시간과 타격 시각이 정확히 같으면 시간 종료를 먼저 처리한다. 종료 후 예약된 타격·입력은 모두 폐기한다.

## 11. KO·시간 종료·무승부 연출

승패와 마지막 사건을 **먼저 확정·저장한 뒤** 연출한다. 연출 생략이나 새로고침으로 결과를 다시 계산하지 않는다.

### KO — 종료 확정 시점부터

| 시간 | 연출 |
|---|---|
| 0~120ms | 입력·타이머 정지. 마지막 타격 장면 고정. 기존 명중 정지를 추가로 중복 적용하지 않음 |
| 120~650ms | 패자 병사가 무릎을 꿇고 카드 몸통이 뒤로 기울어 주저앉음. 모자가 옆으로 살짝 기울고 먼지 한 번. 혈흔·카드 파괴 없음 |
| 300~1300ms | 중앙에 금색 프레임의 `K.O.`. 타격 마무리음 한 번 |
| 650~1500ms | 승자 병사가 한 팔을 들어 올림. 내 승리면 `일기토 승리`, 상대 승리면 `일기토 패배`로 문구 전환 |
| 1600ms | 결과 패널 표시. 버튼은 이때부터 사용 가능 |

종료 확정 200ms 후부터 Enter/탭으로 연출을 생략하고 결과 패널을 바로 열 수 있다. 생략 입력이 결과 패널 버튼까지 연달아 실행되지는 않는다.

### 시간 종료

즉시 양쪽 동작을 멈추고 `시간 종료`를 800ms 표시한다. 내부 실제 체력을 비교해 승자를 결정한다. 800~1600ms에 승자는 팔을 들고 패자는 고개를 내린다. 1600ms에 결과 패널을 연다. 두 병사 모두 남은 체력대로 서 있으며 KO 쓰러짐은 재생하지 않는다.

### 무승부

동시 KO면 두 병사의 쓰러짐을 함께 재생하고 `무승부`. 시간 동률이면 두 병사가 서로 인사하고 `무승부`. 결과 패널은 동일하게 1600ms에 표시한다. 추가 라운드나 자동 재경기는 없다.

## 12. 경기 결과 화면

배경은 종료 순간 경기장에 짙은 녹색 60% 막을 씌운다. 중앙 패널 폭 560px, 화면보다 좁으면 좌우 16px 여백. 패널 높이 최대 90%, 하단 복귀 버튼 고정.

표시 순서:

1. `일기토 승리 / 일기토 패배 / 무승부` — 본편 포커 승패와 다른 제목.
2. `♥9 vs ♣K`, 상대 이름, 종료 사유 `KO / 시간 종료 / 동시 KO`.
3. 양쪽 남은 체력과 소요 전투 시간.
4. **결정적 사건:** 실제 기록을 사용. 예: `♣K의 왕관 강타에 맞아 남은 체력 12가 모두 소진되었습니다.` 시간 종료는 `내 체력 23.4 / 상대 18.6으로 승리`.
5. 통계 표: 양쪽 실제 준 피해 / 직접 명중 타수 / 성공한 방어 타수 / 필살기 사용 횟수.
6. `경기 상세`: 시간순 사건 목록. 시각·기술·상중하·명중/방어/회피/헛침·실제 피해·남은 체력. 기본은 접힌 상태.
7. `정산으로 돌아가기` 주 버튼. 보조 설명 `체스·포커 정산은 그대로 유지됩니다.`

직접 명중 타수는 타격별로 세며, 방어 피해는 직접 명중에 포함하지 않는다. 준 피해는 실제 체력 감소량이므로 잔여 체력을 넘는 피해는 통계에 더하지 않는다. 필살기 사용 횟수는 게이지를 소비하고 시작한 횟수다.

복귀하면 같은 대국의 정산 패널을 다시 열고 `일기토 결과 보기`를 표시한다. 자동으로 다음 대국을 시작하거나 캠페인 엔딩으로 넘어가지 않는다.

## 13. 일시정지·취소·재접속

| 상황 | 처리 |
|---|---|
| Esc / Ⅱ | 즉시 양쪽 전투와 타이머 정지. 유지 입력·예약 입력 해제 |
| 일시정지 패널 | `계속하기`, `조작 보기`, `일기토 종료` |
| 계속하기 | `3·2·1` 후 중단 지점 재개. 카운트다운 중 시간 감소 없음 |
| 일기토 종료 | `이번 일기토를 종료할까요?` → `계속 대결` / `종료하고 정산으로`. 종료 시 `중단` 기록, 금화 변화 없음 |
| 탭 이탈·창 비활성·방향 전환 | 자동 일시정지. 돌아와도 자동 재개하지 않고 계속하기 버튼 표시 |
| 신청 전 Esc | 선택 취소, 정산 복귀. 신청 미소모 |
| 수락 후 VS에서 Esc | 취소 확인. 취소하면 신청은 사용됨 |
| 대기 답변 중 Esc | 확정된 신청은 유지하고 답변 표시로 진행. 결과를 다시 추첨하지 않음 |
| 재실행 시 답변 대기·VS | 저장된 선택과 답변으로 해당 화면 복구 |
| 재실행 시 진행 중 대결 | 첫 버전은 중간 전투 복원을 하지 않음. `이전 일기토가 중단되었습니다.` 안내 후 중단 기록과 정산 복귀 |
| 재실행 시 종료 연출 | 저장된 결과 패널을 바로 표시 |

## 14. AI 실행 규격

첫 구현의 상대는 기존 게임과 같은 로컬 AI다. 화면 표시와 자원·판정은 사람과 동일하다.

- 기술을 결정하는 간격은 300~500ms. 플레이어가 실제로 보여 준 동작과 현재 거리·체력·게이지만 사용한다.
- 기술 선택은 해당 카드의 기본기·콤보·공통 하단기·방어·필살기 목록에서만 한다.
- 필살기 게이지가 부족하면 시전하지 못하고, 공격·회복·피격 중 새 기술을 실행하지 못한다.
- 준비 동작보다 앞서 입력을 읽거나, 반응 지연 없이 방어 자세를 바꾸는 처리를 하지 않는다.
- AI 선택 기록은 사건 로그에 기술 시작으로 남긴다. 내부 판단 문구는 플레이 중 화면에 노출하지 않는다.

## 15. 필요한 화면·미술·음향 자산

| 분류 | 필요한 항목 |
|---|---|
| 화면 | 정산 제안 영역, 카드 선택, 답변/VS, 경기장, 일시정지, 결과, 경기 상세 |
| 배경 | 원경 궁전, 중경 정원·아치, 석판 바닥 각 1개 레이어 |
| 병사 동작 | 대기, 걷기, 앉기, 서서 방어, 앉아 방어, 정권/잽/팔꿈치/찌르기/하단기, 발차기·연권 조합, 피격, KO, 승리, 인사 |
| 병사 표시 | 카드 숫자·문양, 이번 체스 역할의 모자, 내/상대 표식 |
| HUD | 카드 초상 프레임, 체력 프레임·잔상, 4칸 필살기 막대, 시간 프레임, 기술 버튼 4개, 방향 버튼 |
| 효과 | 일반 타격 별, 하단 먼지, 방어 반원, 문양별 필살기 궤적, KO 제목 |
| 음향 | 신청, 수락, 거절, 이동, 휘두름, 일반 명중, 하단 명중, 방어, 필살기 시작·마지막 타격, 카운트다운, KO, 승리·패배·무승부 짧은 종결음 |

여섯 기물의 구체적인 몸동작·포즈·접촉 시각·제작 목록은 [기물 전투 모션 설계 v1](34_CARD_DUEL_MOTIONS.md)을 따른다.

각 기술 동작은 실제 타격 시각에 손·발이 해당 부위에 닿도록 제작한다. 현재 정적인 체카드 그림이 이 동작을 이미 지원한다고 가정하지 않는다. 캐릭터 애니메이션 자산 제작은 향후 구현 작업에 포함한다.

## 16. 구현 완료 시 확인할 항목

- 체스→포커→정산→신청→응답→시작→결과→같은 정산의 모든 버튼이 위 목적지와 일치한다.
- L과 S+L의 방어 판정, ♥9 피해 6 / 5+7 / 8+8+10, 필살기 전부 방어 시 5.2가 명세와 일치한다.
- 피해 숫자·체력 감소·잔상·통계가 같은 사건을 가리키고 실제 체력을 넘는 피해를 표시하지 않는다.
- KO·시간 종료·무승부·중단을 서로 다른 문구와 연출로 표시한다.
- 60초가 멈추는 상황과 진행되는 상황이 양쪽에 동일하며 종료 뒤 타격을 처리하지 않는다.
- 터치 두 개 이상, 키 유지·해제, 화면 이탈·복귀, 새로고침 시 입력과 신청 결과가 올바르게 유지·해제된다.
- 모션 감소·작은 화면에서도 체력·시간·방어 키·복귀 버튼을 확인할 수 있다.

현재 작업은 설계 문서 작성이다. 게임 기능은 아직 구현하지 않았다.
