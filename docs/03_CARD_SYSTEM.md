# 03 · 카드 시스템

## 확정된 덱과 정체성

덱은 스페이드·다이아몬드·하트·클럽 각각 A,2~10,J,Q,K의 52장과 서로 구분되는 조커 2장으로 구성한다. 한 판에 32장의 서로 다른 실물 카드를 배정하고 22장은 미배정이다. 조커의 물리적 식별자도 서로 달라야 한다.

각 기물은 체스 역할과 고정 카드 정체성을 함께 갖는다. 이동·캐슬링으로 정체성이 변하지 않으며, 폰이 어떤 역할로 승격해도 카드가 바뀌지 않는다. 체스 킹 두 개에는 서로 다른 무늬의 K, 체스 퀸 두 개에는 서로 다른 무늬의 Q가 필요하다. 킹의 무늬 집합과 퀸의 무늬 집합 사이에 별도의 상이 조건은 없다. 나머지 기물에는 남은 K/Q와 조커도 배정 가능하다. 초기 체스 킹/퀸에 조커는 금지다.

## 배정 절차 제안 — 승인 대기

1. 고유 실물 카드 54장을 만든다.
2. K 4장 중 2장을 중복 없이 추출해 양측 킹에 배정한다.
3. Q 4장 중 2장을 중복 없이 추출해 양측 퀸에 배정한다.
4. 위 4장을 제외한 50장을 섞고 나머지 28기물에 한 장씩 배정한다.
5. 남은 22장은 해당 판에서 사용하지 않는다.

이 절차는 제약을 충족하는 후보이며 난수 분포, 시드 저장, 재현성, 다음 판 재배정은 Q08이다. 카드 매핑을 공개 로그나 AI 입력으로 전달하지 않는다. 검증용 시드는 개발 분석용 데이터와 사용자에게 보이는 기록을 분리해야 한다.

## 생명주기와 공개

| 상태 | 소유자 | 상대 | 포커 자격 |
|---|---|---|---|
| 생존·미공개 | 정체성 표시 | 체스 역할/위치만 | 있음 |
| 캡처 | 정체성 표시 | 정체성 표시 | 없음 |
| 선택된 쇼다운 카드 | 표시 | 공개 | 선택한 정확히 5장 |
| 폴드한 패 | 표시 | 비공개 유지 | 승부 종료 |
| 미선택 생존 카드 | 표시 | 공개 범위 미정 | 해당 쇼다운 제외 |
| 미배정 22장 | 플레이 UI에서 비공개 제안 | 동일 | 없음 |

상대 킹이 K이고 퀸이 Q라는 제약을 아는 것과 실제 무늬를 아는 것은 다르다. 이동 역할로 카드 랭크를 일반적으로 추정하면 안 된다. 승격 퀸은 Q 카드가 아닐 수 있다.

## 실물 카드와 조커의 가상 값

실물 카드 중복 금지는 확정이다. 조커가 평가 시 취하는 가상 랭크·무늬의 중복 제한은 별도 규칙이며 05에서 제안한다. 조커의 선택된 값은 실물 카드 배정 자체를 변경하지 않는다. 포커 평가 결과를 저장할 때 원래 조커 ID와 가상 값을 구분하는 것이 필요하다.
