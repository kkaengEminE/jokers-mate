# 03 · 카드 시스템

## 덱과 정체

덱은 ♠·♦·♥·♣ 각각 A, 2~10, J, Q, K의 52장과 서로 구분되는 조커 2장(J1, J2)으로 54장이다. 한 판에 서로 다른 실물 카드 32장을 배정하고 22장은 사용하지 않는다.

각 기물은 체스 역할과 고정된 카드 정체를 함께 가진다.
- 이동·캐슬링·승격으로 카드 정체는 바뀌지 않는다. 승격한 퀸은 Q 카드가 아닐 수 있다.
- 양측 킹 2개에는 서로 다른 무늬의 K, 양측 퀸 2개에는 서로 다른 무늬의 Q를 배정한다. 킹 무늬와 퀸 무늬 사이에는 별도 조건이 없다.
- 처음 배치된 킹·퀸에는 조커를 배정하지 않는다. 나머지 기물에는 남은 K·Q와 조커도 배정될 수 있다.

## 배정 절차

1. 고유 실물 카드 54장을 만든다.
2. K 4장 중 2장을 뽑아 양측 킹에 배정한다.
3. Q 4장 중 2장을 뽑아 양측 퀸에 배정한다.
4. 위 4장을 뺀 50장을 섞어 나머지 28기물에 한 장씩 배정한다.
5. 남은 22장은 그 판에서 쓰지 않는다.

매 판 새로 배정한다. 난수는 시드를 공개 기록에 남기지 않으며, 카드 배정은 공개 로그나 컴퓨터 상대 입력으로 전달하지 않는다.

## 카드 상태와 공개 범위

| 상태 | 소유자에게 | 상대에게 | 포커 사용 |
|---|---|---|---|
| 생존·미공개 | 정체 표시 | 체스 역할·위치만 | 가능 |
| 잡힘 | 정체 표시 | 정체 공개 | 불가 |
| 쇼다운에 낸 5장 | 표시 | 공개 | 해당 5장 |
| 포커 단계 공개 1·2·3장 | 표시 | 공개된 카드만 표시 | 확정한 5장 |
| 폴드한 패 | 표시 | 공개된 카드 유지, 나머지 비공개 | 승부 종료 |
| 선택하지 않은 생존 카드 | 표시 | 비공개, 완료 기록에도 넣지 않음 | 해당 쇼다운 제외 |
| 미배정 22장 | 비공개 | 비공개 | 없음 |

상대 킹이 K, 퀸이 Q라는 사실은 알 수 있지만 무늬는 모른다. 기물 역할로 카드 랭크를 추정할 수 없다.

## 조커

실물 카드는 한 판에 중복되지 않는다. 조커가 포커 평가에서 대신하는 가상 카드의 규칙은 [05 포커](05_POKER_SYSTEM.md)에서 정한다. 가상 값은 실물 배정을 바꾸지 않으며, 저장 시 원래 조커 ID와 가상 값을 구분한다.
