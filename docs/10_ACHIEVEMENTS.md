# 10 · 업적과 기록

## 구현 업적

체스: 캐슬링, 앙파상, 승격, 플레이어 체크메이트. 오프닝은 정확한 시작 수순으로 시실리안 `e4 c5`, 이탈리안 `e4 e5 Nf3 Nc6 Bc4`, 퀸즈 갬빗 `d4 d5 c4`를 인식한다. 전치나 전체 ECO 사전은 아직 없다.

포커: 선택 패 족보, 조커 사용, 쇼다운 승리. 베팅: 레이즈, 올인, 체스 패배 후 포커 승리, 상대 참가 불능으로 전체 승리, 자기 참가 불능으로 파산. 블러프 성공은 **하이카드 또는 원페어로 베트/레이즈/올인하고 상대 폴드를 유도한 경우**라는 프로토타입 관찰 지표다. 플레이어의 실제 의도를 추론한 것으로 표시하지 않는다.

## 기록

판 ID, 로컬 날짜·시간, 판 번호, 체스/포커 결과, 최종 잔액, PGN, 공개 캡처 카드, 쇼다운 선택 패, 정산 상세, 업적을 저장한다. 폴드로 끝난 판은 양측 선택 패를 공개 기록에서 비운다. 미선택 생존 카드와 전체 배정은 완료 기록에 넣지 않는다.

최근100판을 로컬 저장하고 JSON으로 내보낸다. 진행 저장은 별도이며 이어하기를 위해 숨은 카드도 포함한다. 로컬 저장 용량 실패는 사용자에게 알린다. 오프닝 확장·수순 시각 리플레이·클라우드 기록은 후속 범위다.
