## 우선 승인 묶음

첫째 Q01의 정산 의미와 대표 예시 E01~E20을 검토한다. 둘째 Q02의 종료 순서와 Q03의 포커 비교 규칙을 결정한다. 셋째 Q04~Q06으로 정보 경계와 베팅 상태 전이를 확정한다. Q07은 원문 확보 시 전 문서와 대조한다. 이 단계에서는 어떤 항목도 사용자의 침묵으로 승인 처리하지 않는다.

## 충돌·오해 방지

- ‘체스 승리비 20’이라는 과거 표현은 후속 ‘카드를 이기던 지던 20이 남는다’와 현재 명세의 최종 잔액 하한으로 해석했다. 항상 팟에서 별도 20을 받는 모델은 채택하지 않는다.
- ‘무승부면 다 가져간다’는 양측 유효 투입 팟에 관한 말이다. 미베팅 골드까지 몰수하는 규칙으로 확대하지 않는다.
- 실물 카드 중복 금지와 조커 가상 값 중복 제한은 서로 다른 결정이다.
- ‘표준 체스’만으로 청구 무승부 UI나 라이브러리 자동 종료 정책까지 확정되지 않는다.
- 앞선 사용자 ‘추천대로’의 정확한 대상이 보이지 않으므로 기존 승인을 무효화하지도, 내용을 추정하지도 않는다.
