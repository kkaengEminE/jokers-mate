# 16 · v0.2 검증 기록

검증일: 2026-10-21. Node22.22.2, TypeScript, Vitest, Vite 및 내장 브라우저로 확인했다.

## 자동 검증

총72개 테스트 통과. 범위:32장 고유 배정·K/Q 제약, 불법 수 거부, 캡처·앙파상·캐슬링·승격 정체성 유지, 체크메이트/5기물/체크 탈출/역체크/앙파상 발견 체크/반복 종료, 전체 족보·조커1~2장·A-low·무늬 비교, 원장 예시20개, 여러 스택의 보존·하한·대칭 검증, 체크/레이즈/콜/폴드·짧은 올인·참가금 전액 올인, 입력 거부, 정보 경계, 저장 복구·오염 검출, 캡처 위주4경기,16장 중 조커2장 최적 패, Worker 및 네트워크 없는 응수, 취소된 패 추천.

검증 중6-high를 휠로 오인하던 비교 오류를 수정하고 회귀 테스트로 고정했다. 체스5기물 테스트의 잘못된 체크 포지션도 수정해 실제 체크가 발생하는 FEN을 사용했다.

`npm run build`의 타입 검사와 프로덕션 빌드 통과. `npm audit` 결과 알려진 취약점0개(검증 당시). 개발 fixture는 프로덕션에 포함하지 않는다.

## 브라우저 검증

- 첫 수 e4 후 컴퓨터 응수 확인.
- 체스 종료 QA 상태에서 패 추천→선택 잠금→올인→쇼다운을 조작했다. 조커 로열 플러시 승리 시 상대 체스 승자의20을 보존한1980/20 결과를 확인했다.
-390px 폭과 데스크톱 배치를 확인.390px에서 가로 넘침 없음.
- 사용자 멈춤 신고 후 계속 실행되는 로컬 서버로 전환하고 기존 판을 새로고침했다. 컴퓨터 응수 후 ‘당신의 차례·3번째 수’와 수순 `e4 c6 / Nf3 e6`를 확인했다.
- 폴드 비공개·저장 검증은 자동 테스트로 확인했다. 모든 희귀 수순을 수동 브라우저 조작으로 반복하지는 않았다.
