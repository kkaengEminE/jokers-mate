# 09 · 구현된 화면과 조작

## 체스

중앙8×8 보드, 좌상 상대 금고·우상 상대가 잡은 카드, 좌하 내가 잡은 카드·우하 내 금고로 배치한다. 양측은 180도 회전 대칭 구조다. 자신의 기물 아래에는 카드 정체성을 표시하고 상대는 뒷면 기호를 표시한다. 캡처 카드는 양측 캡처함에 공개한다.

기물을 클릭한 뒤 도착 칸을 클릭한다. 선택 칸, 가능한 이동, 마지막 수, 체크 상태를 표시한다. 승격은 퀸·룩·비숍·나이트 중 직접 선택한다. 컴퓨터 차례에는 보드 입력을 막고 응수 후 다시 활성화한다.

## 포커와 정산

보드는 타원형 정원 테이블로 바뀐다. 상대 패는 위, 자기 패는 아래, 중앙에는 팟을 둔다. 선택 카드에는 체크 표시와 들림 효과를 적용한다. 최적 패 추천, 조커 치환 결과, 카드 선택 수를 표시한다.

베트/레이즈 입력은 이번 판의 참가금을 포함한 **총 투입액**이다. 콜 필요액, 미투입 금고, 양측 누적 투입액을 함께 표시한다. 팟은 정산 전까지 총 투입액이며, 미대응 반환과 보호 조정은 결과 패널에서 확인한다. 단순 CSS 마차·시종 깃발 효과를 사용한다.

정산은 내 손익, 경합 팟, 반환액, 보호 조정액, 최종 금고, 다음 판/새 게임을 표시한다. 폴드 시 상대 패를 공개하지 않는다.

## 반응형·접근성

넓은 화면은 보드와 사이드 패널의2열, 좁은 화면은 세로 흐름이다. 390px 폭에서 가로 넘침을 확인했다. 버튼과 칸에는 읽기용 이름, 선택 상태, 키보드 포커스를 제공한다. 대화상자는 포커스를 내부에 유지하고 Escape로 닫는다. 모션 설정 및 시스템 reduced-motion을 반영한다. 터치 드래그 대신 클릭/탭 이동을 사용한다.
