# 09 · 화면과 조작

## 화면 원칙

- 데스크톱 16:9 게임 장면이 기준이다(1280×720 / 1920×1080). 홍보용 큰 제목이나 스크롤되는 문서형 사이드바는 두지 않는다.
- 배치: 중앙에 체스판/포커 테이블, 좌상 상대 금고 · 우상 상대 포획함 · 좌하 내 포획함 · 우하 내 금고. 양측은 180도 회전 대칭이다.
- 상단에 작은 상태줄: 대국 번호 / 단계 / 현재 차례 / 일시정지.
- 하단 컨트롤에는 지금 할 수 있는 합법 행동만 둔다. 한 화면에 주 행동은 하나다.
- 기록·족보 설명은 필요할 때 열고 닫는 패널로 둔다.
- 좁은 창에서도 데스크톱 배치를 축소해 유지하며 세로 웹페이지로 바꾸지 않는다. 모바일은 별도 가로 배치를 나중에 설계한다. 전체화면/창모드 전환을 제공한다.

## 상태 메시지

고정 메시지 예: ‘내 차례’, ‘상대가 생각 중’, ‘체스 종료 — 포커로 이동’, ‘패 5장 확정’, ‘상대가 40G 베팅 — 콜 필요 40G’, ‘정산 중’. 계산 실패·오류는 정상 ‘생각 중’과 다른 표시와 복구 버튼으로 보여준다. 버튼을 화면 밖에 배치하지 않는다.

## 체스 화면

- 내 기물 아래에는 카드 정체를, 상대 기물은 뒷면을 표시한다. 잡힌 카드는 양측 포획함에 공개한다.
- 기물을 클릭한 뒤 도착 칸을 클릭한다. 선택 칸, 이동 가능 칸, 마지막 수, 체크 상태를 표시한다.
- 승격은 퀸·룩·비숍·나이트 중 직접 고른다.
- 컴퓨터 차례에는 보드 입력을 막고, 응수 후 다시 연다.
- 체스가 끝나면 마지막 판을 보존한 채 결과와 ‘포커로 이동’ 버튼을 보여준다.

## 포커 화면

- 보드가 타원형 정원 테이블로 바뀐다. 상대 패는 위, 내 패는 아래, 중앙에 팟.
- 생존 병사들이 모자를 벗고 카드로 정렬되는 전환으로 두 게임의 연결을 보여준다.
- 선택한 카드는 체크 표시와 들림 효과. 최적 패 추천, 조커 치환 결과, 선택 수를 표시한다.
- 베팅 입력에는 콜 필요액, 남은 금고, 양측 누적 투입액을 함께 표시한다. 체스몫은 포커 베팅액에 포함해 보여주지 않는다.
- 폴드 시 상대 패를 공개하지 않는다.

## 정산 화면

큰 제목은 이번 판 순손익(“이번 판 +10G”), 작은 설명은 체스/포커 각각의 결과. 시작 잔액 → 참가금·추가 베팅 → 미매칭 반환 → 체스 배당 → 포커 배당 → 최종 잔액을 양측 모두 보여준다. 버튼은 [08 게임 흐름](08_GAME_FLOW.md)의 정산 상태를 따른다.

## 종자·수레·금화 연출

연출은 반드시 실제 게임 사건과 원장 금액에 연결한다.

| 사건 | 연출 |
|---|---|
| 예치·베팅 | 해당 금고 열림 → 종자가 수레에 정확한 금액 적재 → 중앙 도착 → 내려놓기 → 팟 숫자 강조 → 빈 수레 귀환 |
| 체크 | 빈손으로 차례를 넘기는 깃발, 금화 이동 없음 |
| 폴드 | 당사자 종자의 흰 깃발, 그 패는 공개하지 않음 |
| 정산 | 체스 배당과 포커 배당을 구분한 주머니 → 받을 금액이 있는 종자만 접근 → 각 금고로 회수 |
| 미매칭 반환 | ‘승리금’이 아닌 ‘미매칭 반환’ 주머니로 구분 |

- 연출은 확정된 결과를 보여줄 뿐 금액을 다시 계산하지 않는다. 건너뛰기·새로고침·백그라운드에서도 이중 차감/지급이 없다.
- 애니메이션을 끄면 숫자와 텍스트 상태를 즉시 보여준다.
- 행동마다 긴 연출을 강제하지 않는다. 첫 회 설명과 이후 빠른 연출을 나눈다.

## 대사

같은 상대가 상황에 맞는 짧은 한 줄만 말한다. 반복되는 판에서는 긴 설명을 재생하지 않는다. 대사를 패 강도나 숨은 카드와 연결해 정보를 흘리지 않는다.

## 접근성

버튼과 칸에는 읽기용 이름, 선택 상태, 키보드 포커스를 제공한다. 대화상자는 포커스를 내부에 가두고 Escape로 닫는다. 모션 설정과 시스템 reduced-motion을 따른다. 터치 드래그 대신 클릭/탭 이동을 쓴다.
