# 경제 개편 제안 — 2026-10-21

상태: 결과 화면 개선은 구현. 아래 경제 변경은 사용자 선택 대기이며 현재 게임에 적용하지 않음.

## 현재 문제와 사실
현재 각자 20G 참가금, 총 40G가 포커에 걸린다. 체크/체크는 0G 게임이 아니라 40G 쇼다운이다. 폴드도 이미 낸 참가금을 잃는다. 체스 승리의 보상은 골드 지급이 아니라 최종 잔액 20G 보호다. 따라서 체스 승리만으로 반복 수익이 발생하지는 않는다. 그러나 시작 잔액이 20G인 체스 승자는 포커에서 패해도 최종 20G를 돌려받으므로 무위험 예외가 발생한다. 기존 화면의 정산 후 빈 팟 0G가 손익 0G처럼 보이는 별도 표시 문제도 있다.

## 추천: 각자 체스 10G + 포커 10G 사전 납부
- 새 판은 체스와 포커 각 한 번으로 구성. 시작 잔액 최소 20G.
- 총 20G를 처음부터 잠근다. 체스용 10G와 포커용 10G를 별도 원장에 기록한다.
- 체스 승자는 체스 팟 20G를 받는다. 체스 무승부는 각자 10G 반환.
- 포커 팟은 최소 20G. 체크/체크도 반드시 쇼다운. 폴드는 포커 참가금과 이미 매칭된 추가 베팅을 잃는다.
- 체스 배당은 이번 포커의 추가 베팅에 재사용하지 않고 최종 정산까지 잠근다. 부족한 상대에게서 더 많은 금액을 따는 것을 방지한다.
- 포커 종료 후 시작 잔액, 체스 순손익, 포커 순손익, 초과액 반환, 최종 잔액을 양쪽 모두 표시.
- 다음 판은 새 카드로 체스부터 시작. 같은 패의 포커 재경기는 제공하지 않는다.
- 최소 추가 베팅/정상 레이즈 20G는 기존 프로토타입 설정 유지 가능. 참가금과 다른 개념으로 표시한다.

## 보존적 알고리즘 (20G 보호 폐지 선택 시)
B_i: 판 시작 잔액, C_i: 포커 누적 투입액(포커 참가금 10 포함).
체스 예치금은 별도 10. 따라서 10 <= C_i <= B_i - 10.
A_i: 체스 팟 배당(승리20, 무승부10, 패배0).
m = min(C_w,C_b), 초과 반환 R_i=C_i-m, 포커 경합 팟 P=2m.
포커 배당 W_i는 승리 P, 무승부 m, 패배0.
최종 F_i = B_i - 10 - C_i + R_i + A_i + W_i.
항상 합계 보존, 음수 없음. 폴드도 동일 원장에 포커 승자만 지정한다.
체스 배당 A_i는 베팅 가용액에 포함하지 않는다.

## 설계상 중요한 한계
10/10 분리에서도 체스를 이기고 최소 팟에서 포커를 지면 합계 손익0이다. 이는 무료 폴드가 아니라 두 보상이 상쇄되는 구조다. 체스만 이겨서는 꾸준한 이익이 없으므로 기존의 우려인 일방적 수익은 발생하지 않는다. 그러나 매번 체스를 이기는 사람이 포커 위험을 회피하여 자금을 보전하는 전략은 가능하다. 이 전략까지 억제하려면 포커 참가금을 체스보다 크게(예: 체스5/포커15) 하거나 시간/라운드 제한을 두는 추가 결정이 필요하다. 이는 사용자 제안10/10과 달라 임의 적용하지 않는다.

기존 최종20 보장을 유지하면 저잔액 예외는 남는다. 폐지 여부는 명시적 선택을 받는다. 분리 팟에서 체스 배당을 잠그면 결정적 체스 승자는 이미 최소20을 확보하므로 별도 보호 보정이 대부분 불필요하다. 단, 다른 배당비율로 변경할 때는 다시 분석해야 한다.

구현 시 기존 v2 저장 판은 기존 경제로 끝내고 새 판부터 새 경제 버전을 적용한다. 이미 진행 중인 판의 돈 규칙을 바꾸지 않는다. 원장·복원 검증·기록 내보내기·UI·컴퓨터 베팅 가용액을 함께 변경해야 한다.

## 목적을 강화한 권고: 체스5 / 포커15
사용자가 지적한 무손실 회피까지 막으려면 체스5G, 포커15G를 권고한다. 위 공식에서 체스 예치10을5로, 포커 최소10을15로 변경한다. 체스 팟은10G, 포커 최소 팟30G다. 기존 최종20 보호는 폐지해야 한다.

| 체스 / 포커 | 최소 베팅 시 내 순손익 |
|---|---:|
| 승 / 승 | +20G |
| 승 / 패 또는 폴드 | -10G |
| 패 / 승 | +10G |
| 패 / 패 | -20G |
| 무승부 / 승 | +15G |
| 무승부 / 패 | -15G |

시작20G로 체스에서 이기고 포커에서 패하면10G가 남아 다음 판 참가가 불가능하다. 이는 보호 폐지의 의도된 효과로 반드시 규칙과 종료 화면에서 고지한다. 모든 올인은 체스 예치5G를 제외한 잔액까지만 허용한다. 포커만 반복하는 별도 모드는 신규 딜과 다른 규칙이 필요하므로 이번 기본 흐름에 포함하지 않는다. 5/15는 수학적 회피 방지에 대한 권고이며 재미·균형은 실제 플레이 테스트가 더 필요하다.
