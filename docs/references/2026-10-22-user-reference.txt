# Joker's Gambit — 세션 전체 기획 및 결정 사항 정리

**정리 기준:** 2026년 10월 22일
**프로젝트:** Joker's Gambit (가제)
**현재 단계:** 게임 기획 및 규칙 설계 → Codex 문서화 준비

이번 세션에서 **네가 직접 지시하거나 수정한 내용을 최우선으로 정리**했어. 내가 제안했지만 네가 승인하지 않은 사항은 별도로 구분했어.

특히 여러 번 정정했던 **금화 정산, 체스 종료 조건, 카드 배분 규칙**은 마지막에 합의한 내용을 기준으로 정리했어.

# 1. 프로젝트 개요

## 1.1 게임의 기본 개념

체스와 트럼프 카드 게임을 결합한 전략 게임.

플레이어는 일반적인 체스를 진행하지만, 모든 체스 기물은 트럼프 카드의 정체를 가지고 있어.

체스 단계가 종료되면 살아남은 기물의 카드를 사용해 포커를 진행하고, 베팅 결과에 따라 금화를 획득하거나 잃게 돼.

**게임의 핵심은 체스에서 이기는 것만이 아니라, 포커에서 이길 수 있는 카드들을 전략적으로 살아남기는 것.**

예를 들어 로열 스트레이트 플러시를 완성할 수 있는 기물들이 있다면, 플레이어는 오히려 필요 없는 기물을 희생해 체스 단계를 빠르게 끝낼 수 있어.

반대로 상대가 좋은 패를 가지고 있을 것 같다면 포커에서 무리하게 베팅하지 않고 폴드할 수 있어.

### 개발 목표

- 첫 번째 목표: 웹에서 플레이 가능한 2D 게임
- 장기 목표: 완성도를 높여 Steam 출시 검토
- 초기 플레이: 사용자 대 컴퓨터
- 향후 확장: 사용자 간 대전
- 초기에는 게임성과 규칙 검증을 우선
- 시각적 완성도는 이후 단계에서 발전

# 2. 체스 규칙

## 2.1 기본 체스 규칙

일반적인 체스 규칙을 기반으로 진행해.

| 항목 | 규칙 |
|---|---|
| 체스판 | 8×8 |
| 시작 기물 | 각 플레이어 16개 |
| 이동 | 표준 체스 이동 |
| 체크 | 적용 |
| 체크메이트 | 적용 |
| 캐슬링 | 적용 |
| 앙파상 | 적용 |
| 폰 승격 | 적용 |
| 스테일메이트 | 적용 |
| 킹 포획 | 불가능 |
| 시간제한 | 초기 버전에서는 제외하는 방향 |

**폰이 승격하더라도 원래 가지고 있던 트럼프 카드는 바뀌지 않아.**

예를 들어 ♠7 카드를 가진 폰이 퀸으로 승격하면 체스에서는 퀸처럼 이동하지만, 포커에서는 여전히 ♠7이야.

## 2.2 가장 중요한 특수 종료 조건

네가 직접 수정한 규칙이야.

**양측 모두 5개가 아니라, 어느 한쪽이라도 살아남은 기물이 5개가 되는 순간 체스가 종료돼.**

예시:

현재 상황

나:   6개
상대: 6개

내가 상대 기물 1개 포획

나:   6개
상대: 5개

→ 즉시 체스 종료
→ 포커 단계로 이동

이유는 포커를 진행하려면 각자 최소 5장의 카드가 필요하기 때문이야.

따라서 상대에게 5개가 남은 순간, 내 기물이 6개든 10개든 15개든 체스는 종료돼.

## 2.3 5기물 종료 시 체크 판정

네가 구체적인 예시까지 제시해 확정한 규칙이야.

### 상황 A — 5개가 되면서 체크

나:   6개
상대: 6개

내가 상대 기물을 포획

나:   6개
상대: 5개

동시에 상대 킹에게 체크 발생

→ 즉시 체스 종료
→ 나의 체스 승리

상대가 다음 수에서 체크를 막을 수 있었더라도 기물이 5개가 되었기 때문에 더 이상 수를 둘 수 없어.

따라서 체스에서는 내가 승리한 것으로 처리해.

네가 설명한 대로 시간패와 비슷하게 **정상적인 대응 기회가 남아 있더라도 특수 종료 조건에 따라 승패가 확정되는 구조**야.

### 상황 B — 5개가 되었지만 체크가 없음

나:   6개
상대: 6개

내가 상대 기물 포획

상대: 5개

체크 없음

→ 체스 무승부

### 상황 C — 체크를 방어하면서 상대 기물 포획

상대가 나에게 체크

내가 상대 기물을 잡으면서 체크 방어

상대 기물이 5개가 됨

현재 체크 없음

→ 체스 무승부

### 상황 D — 6개 이상 남은 상태에서 체크메이트

나:   6개
상대: 6개

내가 체크메이트 성공

→ 나의 체스 승리
→ 각자 살아남은 카드 중 5장 선택
→ 포커 진행

### 상황 E — 일반적인 스테일메이트

체스 무승부로 처리하고 포커 단계로 이동해.

### 종료 판정 우선순위

| 우선순위 | 조건 | 결과 |
|---|---|---|
| 1 | 체크메이트 | 체크메이트를 만든 쪽 승리 |
| 2 | 한쪽이 5기물 + 체크 | 체크를 건 쪽 승리 |
| 3 | 한쪽이 5기물 + 체크 없음 | 무승부 |
| 4 | 스테일메이트 | 무승부 |
| 5 | 기타 적용되는 체스 무승부 | 무승부 |

모든 체스 이동은 합법적인 이동이어야 해.

자신의 킹을 체크 상태로 만드는 이동은 허용하지 않아.

# 3. 트럼프 카드 시스템

## 3.1 카드 덱

기본적으로 52장의 트럼프 카드와 조커 2장을 사용해.

총 54장이며, 게임 시작 시 양측의 32개 체스 기물에 카드가 배분돼.

나머지 카드는 이번 대국에서 사용하지 않아.

## 3.2 카드 무늬 서열

네가 직접 지정한 한국식 순서야.

**♠ 스페이드 > ♦ 다이아몬드 > ♥ 하트 > ♣ 클로버**

줄여서 **스다하클**.

일반적인 포커 족보를 먼저 비교하고, 족보와 숫자가 같아 승부를 가려야 할 때 이 무늬 서열을 사용하는 방향이야.

무늬를 실제로 어떻게 비교할지는 포커 세부 규칙 문서에서 정확히 정의해야 해.

## 3.3 체스 킹과 퀸의 카드 정체

네가 특히 강조한 규칙이야.

**체스의 킹은 반드시 트럼프 K이고, 체스의 퀸은 반드시 트럼프 Q여야 해.**

트럼프에는 무늬별로 K와 Q가 존재하므로 총 8장이 있어.

| 카드 | 개수 |
|---|---:|
| K | 4 |
| Q | 4 |
| 합계 | 8 |

각 플레이어는 체스 킹 1개와 체스 퀸 1개를 가지고 시작하므로 양측에 K 2장과 Q 2장이 배정돼.

예시:

| 체스 기물 | 나 | 상대 |
|---|---|---|
| 킹 | ♥K | ♠K |
| 퀸 | ♦Q | ♣Q |

서로의 킹은 다른 무늬이고, 서로의 퀸도 다른 무늬야.

한 플레이어의 킹과 퀸이 같은 무늬일 필요는 없어.

## 3.4 나머지 기물의 카드 배정

룩, 비숍, 나이트, 폰은 남은 카드 중 무작위로 배정해.

중요한 점은 **킹과 퀸에 배정되지 않은 나머지 K와 Q도 일반 기물에 배정될 수 있다는 것**이야.

예를 들어:

| 체스 기물 | 카드 |
|---|---|
| 킹 | ♥K |
| 퀸 | ♦Q |
| 룩 | ♠A |
| 비숍 | ♣K |
| 나이트 | ♠Q |
| 폰 | ♠10 |

비숍이 K를 가지고 있어도 체스에서는 비숍처럼 이동해.

나이트가 Q를 가지고 있어도 체스에서는 나이트처럼 이동해.

반드시 나머지 K와 Q가 모두 등장하는 것은 아니야. 배분되지 않고 남을 수도 있어.

**카드의 정체와 체스 기물의 이동 능력은 서로 독립적이야.**

# 4. 카드 공개 및 포획

## 4.1 카드의 공개 범위

- 자신의 카드 정체는 확인할 수 있어.
- 상대의 카드는 뒷면으로 표시돼.
- 상대 기물의 체스 종류는 모자 형태로 확인할 수 있어.
- 포획된 카드는 정체가 공개돼.
- 포획된 카드는 포커에서 사용할 수 없어.

체스 기물이 어떤 카드인지 알 수 있기 때문에 자신의 포커 전략을 세울 수 있어.

반대로 상대가 어떤 카드를 가지고 있는지는 추측해야 해.

## 4.2 포획함

각 플레이어에게 포획함이 있어.

내 포획함에는 내가 잡은 상대 기물이 들어가고, 상대 포획함에는 상대가 잡은 내 기물이 들어가.

포획된 기물의 카드 정체는 공개된 상태로 유지해.

# 5. 포커 시스템

## 5.1 포커 시작 조건

체스가 종료되면 살아남은 기물로 카드 게임을 시작해.

**포커에 사용할 수 있는 카드는 살아남은 기물의 카드뿐이야.**

잡힌 카드를 다시 가져오거나 새로운 카드를 뽑지 않아.

## 5.2 카드 5장 선택

살아남은 기물이 정확히 5개라면 그 5장을 그대로 사용해.

6개 이상이라면 원하는 5장을 선택해.

예를 들어:

살아남은 기물 8개

킹     ♥K
퀸     ♦Q
룩     ♠A
비숍   ♠K
나이트 ♠Q
폰     ♠J
폰     ♠10
폰     ♣3

이 경우 다음 5장을 선택할 수 있어.

♠10
♠J
♠Q
♠K
♠A

→ 로열 플러시

체스 킹과 퀸이 살아 있어도 포커 패에 반드시 포함할 필요는 없어.

## 5.3 전략적 기물 희생

이건 네가 설명한 게임의 핵심 전략이야.

좋은 포커 패를 가진 기물을 최대한 살리고, 필요 없는 기물은 희생할 수 있어.

예를 들어 로열 플러시를 완성할 수 있다면 그 카드들을 가진 기물은 보호하고 나머지 기물을 적극적으로 교환할 수 있지.

그 결과 자신의 기물이 5개가 되는 순간 체스가 끝나고, 강한 포커 패로 승부할 수 있어.

다만 **체스 킹은 일반 체스 규칙에 따라 포획되거나 희생될 수 없어.**

따라서 킹을 일부러 죽여서 체스를 끝내는 전략은 불가능하고, 킹이 아닌 기물을 희생하는 방식으로 구현해야 해.

## 5.4 포커 족보

일반적인 5장 포커 족보를 사용해.

| 순위 | 족보 |
|---|---|
| 1 | 로열 플러시 |
| 2 | 스트레이트 플러시 |
| 3 | 포카드 |
| 4 | 풀하우스 |
| 5 | 플러시 |
| 6 | 스트레이트 |
| 7 | 트리플 |
| 8 | 투페어 |
| 9 | 원페어 |
| 10 | 하이카드 |

카드 교환 없이 살아남은 카드 중 5장을 선택하는 방식이므로, 일반적인 파이브 카드 드로우와는 구별되는 자체 포커 방식이야.

## 5.5 베팅

포커 단계에서 다음 행동을 사용해.

- 체크
- 베트
- 콜
- 레이즈
- 폴드
- 올인

상대가 강한 패를 가지고 있다고 판단하면 체스에서 승리했더라도 폴드할 수 있어.

폴드하면 상대가 유효한 판돈을 가져가고, 카드를 공개하지 않아.

베팅 라운드 수와 정확한 진행 순서는 문서화 단계에서 추가로 결정해야 해.

# 6. 조커 규칙

조커는 2장을 사용해.

초기 버전에서는 **와일드카드 역할만 적용**하기로 했어.

| 항목 | 규칙 |
|---|---|
| 조커 수 | 2장 |
| 등장 | 무작위 |
| 킹 배정 | 불가능 |
| 퀸 배정 | 불가능 |
| 기타 기물 배정 | 가능 |
| 체스 이동 능력 변경 | 없음 |
| 포커 효과 | 와일드카드 |
| 추가 특수 능력 | 초기 버전 제외 |

조커는 포커에서 유리한 카드로 대체할 수 있어.

단, 조커가 항상 게임에 등장하는 것은 아니야.

전체 54장 중 32장만 배분하므로 두 조커가 모두 등장하지 않을 수도 있어.

### 보류한 아이디어

초기에는 구현하지 않지만 다음과 같은 아이디어를 논의했어.

- 조커를 이용한 특수 족보
- 조커 2장 조합
- 판돈 배수 효과
- 상대 카드 변환
- 특수 승리 효과

이러한 능력은 프로토타입 검증 이후 다시 판단하기로 했어.

# 7. 금화 시스템 — 가장 중요하게 정정한 규칙

이 부분은 이전 답변에서 내가 여러 번 잘못 이해했기 때문에, **네가 마지막으로 설명한 정산 원칙을 기준으로 정리**할게.

## 7.1 기본 금화

양측은 각각 1,000골드로 시작해.

나       1,000 G
상대     1,000 G
────────────────
총합     2,000 G

**금화는 새로 생성되지 않아.**

상대에게서 획득하거나 상대에게 잃는 구조야.

## 7.2 체스 참가비

각자 20골드를 내고 체스를 시작해.

나       20 G
상대     20 G
────────────────
중앙     40 G

중요한 점은 **체스가 끝났다고 참가비를 바로 지급하지 않는다는 것**이야.

체스 결과는 기록하고, 금화는 중앙에 남겨둬.

포커까지 끝난 뒤 한 번에 정산해.

## 7.3 체스 승리 보장

네가 반복해서 강조한 규칙이야.

**체스에서 승리한 플레이어는 포커에서 패배하더라도 최종적으로 20골드를 보장받아.**

예를 들어 내가 체스에서 이기고 포커에서 올인해 졌다면:

나       20 G
상대  1,980 G
────────────────
총합  2,000 G

반대로 내가 체스에서 패배하고 포커에서 올인해 승리했다면:

나     1,980 G
상대      20 G
────────────────
총합   2,000 G

체스 승리자가 누구든 포커 결과와 관계없이 20골드는 남는다는 의미야.

## 7.4 체스 무승부

**체스가 무승부라면 승리 보장금은 없어.**

네가 특히 정정한 부분이야.

무승부에서는 참가비를 별도로 획득하거나 돌려받는 규칙이 없어.

포커 승자가 판돈을 가져가.

예를 들어 양측이 모든 금화를 걸었고 내가 포커에서 승리했다면:

나     2,000 G
상대       0 G
────────────────
총합   2,000 G

반대로 포커에서 졌다면 내가 0골드가 돼.

## 7.5 체스·포커 결과 조합

| 체스 결과 | 포커 결과 | 최종 처리 |
|---|---|---|
| 승리 | 승리 | 포커 판돈 획득, 체스 승리 보장 적용 |
| 승리 | 패배 | 포커에 건 금화 손실, 체스 승리 보장 20골드 확보 |
| 패배 | 승리 | 상대의 체스 승리 보장 20골드를 제외한 유효 판돈 획득 |
| 패배 | 패배 | 참가비와 포커 베팅 금화 손실 |
| 무승부 | 승리 | 체스 승리 보장 없이 포커 판돈 획득 |
| 무승부 | 패배 | 체스 승리 보장 없이 포커 판돈 손실 |

**체스 참가비와 포커 판돈을 각각 별도 승리 보상처럼 지급하지 않는 것**이 핵심이야.

다만 일반적인 소액 베팅에서도 체스 승리 보장금 20골드를 어떻게 보호할지, 이미 금고에 남은 금화와 어떻게 합산할지는 정산 함수 설계 시 명확히 해야 해. 위의 올인 사례는 확정된 기대 결과야.

## 7.6 전체 게임 패배 조건

네가 직접 확정했어.

**다음 체스 대국에 참가할 수 있는 20골드가 없다면 즉시 전체 게임 패배.**

| 남은 금화 | 상태 |
|---|---|
| 100골드 | 계속 진행 |
| 40골드 | 계속 진행 |
| 20골드 | 계속 진행 |
| 19골드 | 최종 패배 |
| 0골드 | 최종 패배 |

0골드가 아니더라도 참가비를 낼 수 없으면 게임이 끝나.

금화가 20골드 미만으로 남아 있더라도 별도로 몰수하지 않아.

# 8. 게임 화면 배치

## 8.1 체스 화면

**상대와 내 배치는 180도 회전 대칭**이야.

┌──────────────────────────────────────────┐
│                                          │

│                                          │

│               │        │                 │

│                                          │
│   [내 포획함]           [내 금고]         │

|---|---|

| 우측 상단 | 상대 포획함 |

| 중앙 | 체스판 |

각 플레이어의 시점에서 포획함은 왼쪽, 금고는 오른쪽에 있는 구조야.

## 8.2 포커 화면

체스가 종료되면 체스판이 포커 테이블처럼 전환돼.

┌──────────────────────────────────────────┐
│                                          │
│ [상대 금고]              [상대 포획함]   │
│                                          │
│           [상대 카드 5장]                │
│                                          │
│                                          │
│               ◎ 판돈 ◎                  │
│                                          │
│                                          │
│            [내 카드 5장]                 │
│                                          │
│ [내 포획함]              [내 금고]       │
│                                          │
└──────────────────────────────────────────┘

네가 원하는 연출은 다음과 같아.

### 금화 베팅

1. 플레이어가 베팅 금액을 선택해.
2. 오른쪽 금고에서 수레가 나와.
3. 수레에 금화를 실어.
4. 중앙 판돈 위치로 이동해.
5. 금화를 내려놓아.
6. 수레가 다시 금고로 돌아가.

### 베팅 행동 표시

베팅 버튼은 금고 위쪽에 위치하고, 왕실의 깃발이나 종자의 행동으로 표현해.

특히 폴드하면 **종자가 흰색 깃발을 흔드는 연출**을 원했어.

### 최종 정산

포커가 종료되면 승리 결과에 따라 종자들이 중앙으로 나와 금화를 회수해.

- 체스와 포커 모두 승리했다면 해당 플레이어의 종자가 판돈을 회수
- 체스와 포커 모두 패배했다면 패배한 플레이어의 종자는 회수하러 나오지 않음
- 체스 승리와 포커 승자가 다르면 정산된 몫에 따라 각각 회수

이 연출은 게임의 핵심적인 시각적 특징으로 유지해.

# 9. 아트 및 세계관

## 9.1 기본 스타일

네가 지정한 방향은 다음과 같아.

**아르누보 + 빅토리아 시대 + 중세 왕실 + 이상한 나라의 앨리스**

체스의 킹과 퀸이 중심이 되는 만큼 왕실과 귀족 사회의 느낌을 원했어.

단순한 카지노나 현대식 카드 게임보다는 동화적이고 고풍스러운 분위기야.

## 9.2 카드 캐릭터

모든 기물은 트럼프 카드 병사처럼 표현해.

기본 형태:

- 카드 형태의 몸
- 얼굴
- 팔과 다리
- 체스 기물 모양의 모자
- 무기 없이 체스 기물의 역할을 표현
- 각 기물의 카드 무늬와 숫자 표시

체스 기물의 정체는 모자로 표현하고, 포커 카드의 정체는 카드 본체로 표현해.

## 9.3 저작권 방향

루이스 캐럴의 원작 문학과 고전 삽화를 참고하되, 디즈니 애니메이션의 독자적인 캐릭터 디자인은 복제하지 않는 방향이야.

시각적 스타일은 초기 프로토타입 이후 구체적으로 결정하기로 했어.

# 15. 이번 세션에서 네가 가장 강조한 10가지

마지막으로 네 지시만 압축하면 다음과 같아.

1. **체스 킹은 반드시 카드 K, 체스 퀸은 반드시 카드 Q다.** 다른 기물도 K와 Q를 가질 수 있다.

2. **카드 무늬 순서는 스다하클이다.** ♠ > ♦ > ♥ > ♣.

3. **어느 한쪽의 기물이 5개가 되는 즉시 체스를 종료한다.** 양쪽 모두 5개가 될 필요는 없다.

4. **5개가 되는 마지막 이동에서 체크가 발생하면 체크한 사람이 체스에서 승리한다.** 상대가 막을 수 있었더라도 종료한다.

5. **5개가 되었지만 체크가 없다면 체스 무승부다.** 체크메이트가 먼저 발생했다면 정상적으로 승패를 판정한다.

6. **포커는 살아남은 카드로만 진행한다.** 5장 이상 남으면 원하는 5장을 고르고, 죽은 카드는 사용할 수 없다.

7. **체스에서 승리하면 포커에서 패배하더라도 20골드가 보장된다.** 금화는 체스 종료 직후 지급하지 않고 포커 이후 정산한다.

8. **체스 무승부에서는 승리 보장금이 없다.** 포커 결과로 판돈의 주인을 결정한다.

9. **20골드 미만이 되면 전체 게임에서 패배한다.** 다음 체스 대국 참가비를 낼 수 없기 때문이다.

10. **화면은 180도 회전 대칭이다.** 상대 금고는 왼쪽 위, 상대 포획함은 오른쪽 위, 내 포획함은 왼쪽 아래, 내 금고는 오른쪽 아래에 배치한다.
