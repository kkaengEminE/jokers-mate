# 28 · 포커 단계 공개 설계 — 승인 및 구현

2026-10-26 사용자가 단일 베팅 후 즉시 공개되는 구조의 한계를 지적하고, 한 장씩 공개하거나 개인 패 두 장을 고르는 방식을 질문했다. 동일 날짜 사용자 승인에 따라 새 포커 시작은 3단계 공개로 구현했다. 이미 시작한 구형 베팅 저장은 단일 라운드를 유지한다. 선택 클릭 순서의 처음 3장이 공개 순서이고 마지막 2장은 비공개다. 추천 패도 순서를 표시하고 다시 선택할 수 있다. 상대는 자기 패만으로 고른 5장의 순서를 무작위 확정한다. 선행자는 각 라운드 홀수 판 백/짝수 판 흑으로 유지한다.

## 추천 실험: 생존 5장 유지, 3장 단계 공개 + 2장 비공개

체스에서 생존한 카드 중 5장을 확정한다. 자신은 처음부터 다섯 장을 알고 있다. 두 장은 비공개로 남기고 나머지 세 장의 공개 순서를 양측이 시작 전에 확정한다. 이후 패·순서를 바꿀 수 없다.

1. 양측 1장씩 동시 공개 → 첫 베팅 라운드.
2. 체크-체크 또는 베팅-콜 등으로 라운드가 종료되면 두 번째 장 동시 공개 → 두 번째 베팅.
3. 세 번째 장 동시 공개 → 마지막 베팅.
4. 마지막 라운드 종료 후 비공개 두 장을 공개하고 기존 5장 족보로 판정.

베팅 버튼을 누를 때마다 공개하지 않는다. 레이즈가 남아 있는 동안은 같은 라운드다. 체크-체크도 다음 공개 단계로 진행하며, 첫 체크-체크로 전체 경기가 끝나지 않는다. 폴드하면 남은 비공개 패를 공개하지 않고 즉시 정산한다. 맞춰진 올인으로 더 베팅할 수 없다면 추가 입력 없이 최종 공개로 진행한다. 미대응 금액 반환은 기존 보존 정산을 유지한다.

참가금은 처음 50G 한 번뿐이다. 공개 단계마다 입장료나 강제 납부를 추가하지 않는다. 체스40/포커60, 체스무승부100포커, 최소잔액보장 없음은 유지한다.

이 방식은 새 카드가 들어오는 역전이 아니라 상대의 완성 패에 대한 정보가 늘어나는 심리전이다. 이미 약한 패임을 아는 사람이 조기 폴드하는 현상은 남으므로 플레이 테스트가 필요하다. 체스와 합친 경기 길이를 고려해 우선 베팅3회 실험을 제안한다.

## 비교: 홀덤형

텍사스 홀덤은 개인2장과 공동5장으로 7장 중 최선5장을 만든다. 공동패는 3장/1장/1장 순서로 공개된다. 출처: https://worldpokerfederation.org/poker/how-to-play-poker/variants-and-rules/how-to-play-texas-holdem/

이 게임에 적용하려면 생존패 중 개인2장을 고르고 공동패5장의 공급원을 따로 정해야 한다. 새로운 카드로 족보가 바뀌는 장점이 있지만, 체스에서 지킨 5장의 의미가 약해진다. 미배정 덱 사용 여부, 잡힌 카드의 재사용 금지, 조커, 양측이 동일한 공동5장을 쓰는 경우의 동률 해소를 재설계해야 한다. 동일한 공동패를 쓰면 무늬 순서만으로도 동률이 해소되지 않을 수 있다.
