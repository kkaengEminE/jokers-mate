## v0.2 구현 전환 · 2026-10-21 갱신

권장 규칙과 구현 범위를 묻는 질문에 사용자가 “게임 구현까지 해줘”로 응답하고 이후 계속 진행을 지시했다. 이에 따라 원래 Phase 1의 코드 작성 제한을 현재 요청에 한해 해제하고 브라우저 프로토타입을 구현했다. 제시한 Q01~Q04 권장안은 적용하고, 추가 기본값은15 문서에 별도로 기록했다. 기존 ‘추천대로’ 답변의 미확인 상태는 유지한다.

사용자의 첫 수 후 멈춤 신고에 따라 Worker 로딩 의존성을 제거했다. 컴퓨터는 로컬 탐색 코드이며 외부 생성형 AI 호출이 없다는 점을 화면/문서에 명시했다. 로컬 실행 서버를 개발 작업 생명주기와 분리했다. 계정 전환·커밋·푸시·회사 계정 복원 요청은 계속 적용한다.
