# 27 · 참고 이미지 적용

그림체와 구도 기준은 [13 미술 방향](13_ART_DIRECTION.md)을 따른다.

## 채택 기준

| 자료 | 채택할 요소 | 그대로 쓰지 않을 요소 |
|---|---|---|
| 체카드 | 문자 그대로 카드인 몸통, 사람 얼굴·손발, 역할별 체스 모자. 여왕/왕/비숍/폰/나이트/룩 | 그림에 고정된 Q♠·K♥ 등의 배정, 서로 다른 구석 무늬 |
| 손 모양 참고 | 플레이어 시점, 선택 시 손의 접근 방향 | 화면의 카드를 손으로 가리기 |
| 베팅 금화 참고 | 금고에서 중앙으로 운반, 금액 단위 선택 | 실제 원장보다 많은 장식 금화·고정 금액 |
| 양옆 잡힌 카드와 규칙책 | 양측 포획함, 언제든 여는 책 형태의 도움말 | 읽을 수 없는 생성형 영문 규칙 |
| 사람 의상에 카드 무늬 | 보류 후보로 보관 | 체카드의 대체 기본 캐릭터로 채택하지 않음 |
| 내 카드 앞·상대 반대편 | 내 패 전면, 맞은편 상대와 뒷면 패 | 공중에 떠 있는 상대 패 |
| 체스버전 / 체스판 화면 의견 | 목제 보드, 정원, 대칭 공간 | 틀린 좌표·기물 배치, 체스 중 의미 없는 포커 5장 |
| 카드 구조는 엉망… | 상대가 건너편에 앉은 구도 | 잘못된 앞뒤 방향, 중복 패 |
| 카드게임 | 양측 패와 중앙 팟의 분리 | 추가 공유 카드처럼 보이는 장식 카드 |
| 포커 시작 | 내 5명과 상대 5명의 대치 | 쇼다운 전 상대 정체 공개 |

## 자산과 구현

`public/art/royal-garden-v1.png`는 정원 배경, `public/art/checards-v1.png`는 빈 몸통을 가진 6역할 투명 시안이다. `src/Checard.tsx`가 역할과 실제 카드 정보를 합성한다. [생성 프롬프트](art/GENERATION_PROMPTS.json)는 내장 image_gen 자산 제작 입력이다.

현재는 포커 정원 배경·확대 체카드·양피지 판돈 안내판과 ±0.6도/1px idle을 사용한다. 모션 끄기와 reduced-motion에서 정지한다. 규칙책 버튼은 통합 규칙 창을 연다. 참고의 가로 발코니 구도·손·석조 판돈 받침·상대 인물·최종 펜화 자산은 제작 대상이다.
