## 장면 설계

체스는 정원 속 읽기 쉬운 평면 8×8 목제 보드를 중심으로 둔다. 원근으로 클릭 칸을 찌그러뜨리지 않는다. 왼쪽은 내 금고·포획함, 오른쪽은 상대 금고·포획함. 아래에는 규칙책과 현재 차례를 둔다. 마지막 수와 결과 확인은 그대로 남긴다.

포커는 같은 정원의 시점에서 상대를 위, 내 패를 아래, 팟을 가운데 둔다. 체카드 모자는 체스에서 살아남은 역할을 기억하는 시각 요소이며 포커 족보에 영향을 주지 않는다. 모자를 벗는 연출은 필수가 아니며 1차 구현은 유지한다. 상대 카드의 그림·이름·접근성 설명 모두 공개 정책을 따른다. 폴드에서는 공개하지 않는다.

메뉴는 같은 정원을 배경으로 새로하기/이어하기/설정/나가기만 명확하게 제시한다. 프롤로그·엔딩·초상은 별도 제작 과제로 둔다. 참고 이미지 자체를 완성 게임 화면처럼 한 장으로 붙이지 않는다.

## 자산 분리

- `public/art/royal-garden-v1.png`: 글자·카드·기물 없는 정원 배경.
- `public/art/checards-v1.png`: 6역할 투명 스프라이트. 몸통은 비어 있고 실제 카드 표시는 DOM에서 합성.
- `src/Checard.tsx`: 모자=현재 체스 역할, 몸통=고정 카드 정체. 승격해도 카드가 바뀌지 않는다. 상대 카드 객체는 컴포넌트에 전달하지 않는다.
- 스프라이트 시트는 원본 래스터를 편집하지 않고 SVG viewBox로 역할별 영역만 표시한다.
- [생성 프롬프트](art/GENERATION_PROMPTS.json): 내장 image_gen 사용. 새 시안이며 최종 원화 승인으로 간주하지 않는다.
