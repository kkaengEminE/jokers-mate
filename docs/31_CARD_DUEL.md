# 카드 일기토

상태: 향후 기능 아이디어. 지금은 기획만 기록하며 플레이 기능은 구현하지 않는다.

카드 게임이 끝나면 내 게임 카드 중 한 장을 골라 상대에게 일기토를 신청한다. 상대가 수락하고 자신의 카드 한 장을 고르면 별도의 1대1 대전이 시작된다. 거절하면 원래 결과 화면으로 돌아간다.

## 대전 방식

- 횡스크롤 격투 게임 느낌의 1대1 대전. 좌우로 이동해 접근하고 거리에 맞는 기술을 쓴다.
- 카드마다 랜덤한 속성과 기술 구성이 있다. 카드의 숫자나 포커 족보가 전투력을 결정하지 않는다.
- 네 개의 기술 버튼으로 정권, 발차기 콤보, 방어, 필살기를 사용한다. 각 카드의 필살기는 하나다.
- 예시: ♥9는 정권, 발차기 콤보, 상단 방어, 상·중·하 연속 차기 필살기를 가진다.
- 체력, 거리, 기술 재사용 시간, 필살기 게이지를 보여 준다. 체력이 먼저 소진되면 패배하며 제한 시간이 끝나면 남은 체력을 비교한다.
- 일기토는 선택 사항이며 원래 카드 게임의 승패와 정산을 바꾸지 않는다.

## 추후 결정할 사항

현재 상대는 컴퓨터이므로 첫 구현에서는 상대 AI가 수락 또는 거절하고 카드를 선택하는 방식을 제안한다. 플레이어 조작은 키보드와 화면의 터치 버튼을 지원할 수 있다. 카드 속성의 추첨 시점과 유지 기간, 수락·거절 기준, 기술별 판정과 밸런스는 구현 전에 정한다. 체력·제한 시간·게이지·원래 정산과의 분리는 위 아이디어를 구체화하기 위한 제안이다.

실시간 온라인 대전, 별도 격투 캐릭터 아트, 보상과 성장 시스템은 별도 작업으로 정한다.
