# 카드 일기토 — 기획 개요 v0.3

작성 기준: 2026-11-03. 상태: 설정에서 독립 실행하는 테스트 대결 구현. 본편 정산 후 신청 흐름은 후속 설계.

## 사용자가 요청한 기능

카드 게임이 끝나면 내 카드 중 한 장을 골라 상대에게 일기토를 제안한다. 상대가 수락하면 양쪽이 고른 카드 병사로 실시간 1대1 대전을 한다. 이동과 네 개의 기술 버튼을 사용한다. 예시인 ♥9는 정권·발차기 콤보·상단 방어·상중하 연속 차기 필살기를 가진다.

최신 요청에 따라 카드 능력은 **기물·문양·숫자 세 요소로 고정 배정**한다. 기물은 기본기와 연계 마무리, 숫자는 콤보·필살기 구성, 문양은 수치 보정과 방어 특성을 맡는다. `설정 → 대결 모드 테스트`에서 양쪽 조합을 자유롭게 고르고 플레이할 수 있다. 본편 정산 후 제안·수락 연결은 아래 설계로 유지한다.

기술의 원본 수치는 조합식 문서, 화면과 대전 처리 순서는 화면·조작·전투·연출 설계서, 기물별 몸동작은 전투 모션 설계서를 기준으로 한다. 숫자·문양 고정 배정과 신청 후 수락 절차는 사용자 요청이며, 제한 시간·확률·피해 계수·색상·연출 길이는 구체화한 설계 제안이다.

## 전체 연결

```text
체스 종료 → 체스 결과 → 포커 패 선택·베팅·쇼다운 → 금화 정산
  ├─ 기존 다음 대국 / 엔딩 / 실패 화면
  └─ 카드 일기토 제안 → 내 패 다섯 장 중 선택 → 상대 응답
       ├─ 거절 → 정산 복귀
       └─ 수락 → VS 소개 → 대결 시작 → 60초 단판 → 결과 → 같은 정산 복귀
```

- 시작 위치는 본편의 최종 정산 화면이다. 체스 직후에는 기존 포커를 계속하며, 일기토는 본편 정산 이후 선택한다.
- 후보는 양쪽이 이번 쇼다운에 실제 제출한 다섯 장이다. 포획된 카드·미제출 생존 카드·이전 판 카드는 후보가 아니다.
- 폴드·대국 포기 판은 상대 비공개 패를 유지하고 일기토를 제공하지 않는다.
- 정상 쇼다운으로 끝난 캠페인 승리·실패 판에서는 일기토 후 기존 엔딩·실패 화면으로 갈 수 있다.

## 대전 기본값

- 2D 측면 경기장, 플레이어 대 내장 AI, 60초 1라운드.
- 체력 100, 필살기 게이지 0에서 시작. 최대 100, 사용 시 100 소비.
- A/D 또는 방향키로 이동, S/↓로 앉기. J 기본기, K 콤보, L 유지 방어, S+L 하단 방어, I 필살기.
- S+J는 모든 카드의 공통 하단 쓸기. 카드마다 네 기술 슬롯과 필살기 하나를 유지한다.
- 체력 0은 KO, 시간 종료는 실제 잔여 체력 비교, 동시 KO·같은 체력은 무승부.
- 체스·포커의 확정 정산·캠페인 결과는 유지한다. 첫 버전은 추가 금화 배당 없이 일기토 결과를 기록한다.

## 신청과 저장

한 대국에서 신청은 한 번이다. 신청 전 카드 선택 취소는 기회를 소비하지 않는다. 신청 확정 후에는 거절·취소·중단도 사용된 신청으로 기록한다.

첫 유효 신청은 반드시 수락한다. 이후 로언 80%, 황제 60% 수락 확률을 제안한다. 상대는 자기 후보 다섯 장 중 균등 확률로 한 장을 고른다. 이 무작위 선택은 상대 답변과 카드 선택에만 적용하며 카드 능력에는 적용하지 않는다.

선택·답변·상대 카드·조합 버전을 저장한 뒤 화면을 진행한다. 전투 결과는 종료 연출 전에 확정한다. 새로고침으로 신청이나 금화 정산을 반복하지 않는다. 진행 중 전투의 브라우저 재실행 복원은 첫 버전에서 중단 처리하며, 신청/VS와 완료 결과는 저장된 화면으로 복구한다.

## 제작 범위

원래 게임의 정산 화면 연결, 선택·응답·VS 화면, 카드 병사 격투 동작, 정원 무대, 체력·필살기 HUD, 키보드·터치 조작, 내장 AI, 피격·종료 연출, 경기 기록을 첫 구현 범위로 삼는다.

온라인 대전·성장·장비·보상 경제·점프와 공중 연속기는 이 설계의 첫 구현 범위에 포함하지 않는다. 설계 수치는 실제 구현 시 검증하고 조합식 버전으로 관리한다.
