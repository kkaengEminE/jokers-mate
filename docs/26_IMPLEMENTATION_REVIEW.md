## 경계 선택
정산 스냅샷이 저장되어 phase=result이면 결과를 보존한다. 활성판으로 저장된 상태를 다시 열면 도주 정산한다. 새로고침도 재실행으로 처리하며 참가 화면에 명시한다. 탭을 숨기면 메뉴로 일시정지할 뿐 패배시키지 않는다. 이 기술적 기본값은 OPEN_QUESTIONS에서 사용자 재검토 가능 항목으로 남겼다.

08의 ‘앱을 닫는 것은 포기가 아니다’는 활성판 도주 규칙과 충돌해 수정했다. 문서상 미래 데이터 필드와 실제 journey/snapshot 구현을11에서 구분했다.
