# 08 · 게임 흐름과 캠페인

## 전체 흐름

메인 → 새로하기 → 프롤로그(새 게임에서만) → 참가 확인 → 체스 → 체스 결과 → 카드 선택 → 포커 베팅 → 쇼다운 또는 폴드 → 정산 → 다음 대국 또는 엔딩 → 메인.

### 쇼다운 화면 흐름

- 마지막 베팅이 끝나면 결과는 즉시 저장하되 정산창은 자동으로 열지 않는다.
- 이미 공개된 카드는 유지하고, 남은 카드를 내 카드 → 상대 카드 순서로 한 장씩 공개한다. 최초 0.9초, 이후 약 0.85초 간격이며 마지막 공개 후 1.2초 동안 양쪽 패를 볼 시간을 둔다. 올인으로 일찍 종료된 판도 남은 카드 전체를 이 순서로 공개한다.
- 공개가 끝나면 게임판 중앙에 양측 족보와 승리·패배·무승부를 표시한다. **계속 · 정산 보기**를 눌러야 정산 팝업과 최종 잔액을 보여준다.
- **공개 건너뛰기**는 승패 화면까지만 이동한다. 폴드는 상대의 미공개 패를 열지 않고 기존 정산 화면을 사용한다.
- 메뉴·도움말을 열거나 앱이 비활성화되면 공개 연출을 멈춘다. 동작 줄이기 설정은 뒤집기 효과를 없애고 대기 시간을 줄인다.
- 새로고침 후에는 저장된 결과로 공개 연출을 다시 볼 수 있다. 연출 재생은 정산을 다시 실행하지 않는다.

## 메인과 설정

- 메인: **새로하기 / 이어하기 / 설정 / 종료**. 이어하기는 이어갈 이야기가 있을 때만 보인다.
- 진행 중인 이야기가 있을 때 새로하기를 누르면 덮어쓰기를 확인한다.
- 설정: 화면·음량·애니메이션·접근성 / Joker’s Mate란? / 체스 규칙 / 포커 규칙 / 이 게임의 특수 규칙 / 캐릭터 소개 / 기록.
- 종료: 데스크톱 앱은 저장 후 종료, 웹은 저장 후 메인으로 가서 탭 닫기 안내(탭을 강제로 닫지 않음), 모바일은 OS 방식.

## 프롤로그

- 새 게임을 만들 때만 한 번 재생한다. 이어하기·다음 대국·메인 복귀에서는 재생하지 않는다. 건너뛸 수 있다.
- 시청 여부를 저장한다. 설정에서 다시 보기는 보조 기능 후보다.
- 구성(제작 목표 30~45초): 지워지는 서명 → 정원의 문 → 책상 위 초대장 → 리브의 선택. 대사 예: 리브 “제 이름이 이 장부에 있었습니다.” 로언 “되찾으려면, 남길 것을 고르십시오.”

## 판 진행 상태

| 상태 | 주요 버튼 | 저장·이탈 처리 |
|---|---|---|
| 프롤로그 | 다음·건너뛰기 | 시청 진도. 아직 참가금 없음 |
| 참가 확인 | 50G 내고 대국 시작·돌아가기 | 아직 미납, 안전하게 나갈 수 있음 |
| 체스 | 합법 수·일시정지 | 진행 저장 + 미완료 판 표시. 나가면 저장된 단계에서 재개 |
| 체스 결과 | 포커로 이동 | 최종 정산 전. 나가면 저장된 단계에서 재개 |
| 카드 선택·베팅 | 선택 확정·합법 베팅 | 최종 정산 전. 나가면 저장된 단계에서 재개 |
| 쇼다운·정산 연출 | 연출 건너뛰기 | 결과를 먼저 저장. 확정된 결과는 취소하지 않음 |
| 정산(양쪽 50 이상) | 계속하기·돌아가기 | 계속하기 = 다음 참가 확인, 돌아가기 = 메인 |
| 정산(상대 50 미만) | 엔딩 보기 | 계속/돌아가기 없음. 재실행해도 엔딩 대기 |
| 정산(내 50 미만) | 실패 화면·메인으로 | 이어하기 삭제 |

참가 확인 화면에서는 현재 잔액, 참가50G 1회 예치·합산 체스40G/포커60G 배당, 추가 베팅 없는 승패별 손익표, 포커 행동 설명을 보여준다. 참가 버튼을 누르기 전에는 금화를 차감하지 않고, 새로고침으로 중복 차감하지 않는다.

## 세 단계의 종료를 구분한다

1. **체스 종료:** 마지막 체스판을 그대로 보여준다. 예: “체스 무승부 — 당신의 기물 5개, 마지막 수에 체크 없음”. 버튼은 ‘포커로 이동’. 이 단계에서 “한 판이 끝났다”고 표현하지 않는다.
2. **한 판 종료:** 포커 승패와 한 번의 정산([06 경제](06_ECONOMY_SYSTEM.md)).
3. **전체 게임 종료:** 어느 한쪽이 50G 미만. 다음 대국 버튼을 없애고 엔딩 또는 실패 화면으로 간다. 남은 골드·총 대국 수·대표 업적·기보를 보여주고 ‘처음부터 다시’와 ‘메인으로’만 제공한다.

## 일시정지와 이탈

- 일시정지 메뉴: 계속하기 / 설정 / **대국 포기하고 메인으로 — 현재 판돈 XXG 손실** 확인.
- 진행 중인 판에는 손실 없이 나가는 ‘저장하고 메인으로’를 두지 않는다. 판을 꺼서 유리한 상태로 되돌릴 수 없어야 한다.
- 메인·일시정지 중에는 컴퓨터가 행동하지 않는다. 창이 비활성화되면 입력·연출을 멈추고 복귀 시 일시정지 화면을 띄운다. 기록을 읽거나 일시정지한 시간만으로 패배하지 않는다.
- 진행 중 메인 복귀·창 닫기·새로고침은 판을 정산하지 않는다. 이어하기는 저장된 단계·차례·납부액을 복원하고 참가금을 다시 차감하지 않는다.
- 정산이 이미 확정된 판은 결과 화면을 보지 않았어도 결과를 유지한다.

## 캠페인 (현재는 검증용 예시)

상대·시작 자금·해금 조건·엔딩 연결은 교체 가능한 캠페인 데이터로 분리한다. 향후 스테이지 구성이 바뀌면 황제는 없어지거나 마지막 상대가 될 수 있다.

| 단계 | 상대 | 시작 금고 | 내 잔액 |
|---|---|---|---|
| 1막 | 로언 | 1000G | 새 게임 1000G |
| 2막 | 황제 아우렐리온 | 2,100,000,000G | 1막 종료 잔액 그대로 이월 |

- 판 하나를 이기면 엔딩 없이 다음 대국으로 간다.
- **로언이 50G 미만** → 일반 승리 엔딩. 엔딩을 다 본 뒤 돌아가기 → 메인의 이어하기가 황제전으로 연결된다.
- **황제가 50G 미만** → 진엔딩. 0G까지 딸 필요는 없다.
- **내가 50G 미만** → 상대가 누구든 전체 게임 오버. 이어하기를 지우고, 새 게임은 로언·각 1000G·새 프롤로그부터. 황제전 체크포인트 부활이나 자금 보충은 없다.
- 활성 판을 중간에 닫으면 진행을 보존하며 도주 패배로 기록하지 않는다. 전체 이야기는 잔액이 참가금 이상이면 계속할 수 있다. 참가 전이나 확정된 정산 이후에 앱을 닫는 것은 도주가 아니다.

## 엔딩

- **일반 엔딩(로언전 승리) — ‘되찾은 서명’:** 로언이 마지막 참가금을 낼 수 없음을 인정 → 장부를 건넴 → 리브가 자기 이름과 지워진 동료의 흔적을 복원 → 정원 문이 열림 → 로언이 왕실의 초대를 건네며 황제를 예고. 이야기 전체의 끝이 아니라 1막의 완결이다.
- **진엔딩(황제전 승리):** 황제의 금고가 참가 불가 → 이중 왕관이 벗겨짐 → 리브에게 왕좌의 권리가 넘어감 → 새 황제의 초상 → 크레딧 → 돌아가기. 로언 엔딩 화면·대사를 이름만 바꿔 재사용하지 않는다. 완료 후 이어하기를 없애고 새로하기만 남긴다.
- **실패 화면 — ‘닫힌 정원’:** 초대장이 접힘 → 문이 닫힘 → “이번 이야기는 여기서 끝났습니다” → 최종 잔액과 성과 → 처음부터 다시 / 메인. 실패 화면은 엔딩으로 부르지 않는다.
- 최종 텍스트·일러스트는 이후 디자인에서 정한다.

## 영구 프로필

캐릭터 소개·칭호·업적·기록은 이야기와 별개인 영구 프로필에 저장한다. 진엔딩을 완료하면 칭호 ‘황제’를 해금해 설정 → 캐릭터 소개에서 **리브 · 황제**를 금색으로 표시하고, 초상을 이중 왕관을 쓰고 체스·카드 왕좌에 앉은 리브로 바꾼다. 새로 시작해도 칭호는 유지한다(초기화는 별도의 명시적 행동).

## 진행 기간

황제 금고는 1000G 대비 압도적으로 크고, 한 판에는 맞춘 금액만 딸 수 있으므로 한 번의 올인으로 끝나지 않는다. 매 판 금고를 두 배로 불려도 약 22회 이상 성공해야 한다. 자동 성장·자금 보충·강제 베팅은 넣지 않으며, 실제 소요 시간을 측정한 뒤 조정한다.

## 흐름 검증 항목

새 게임 프롤로그 1회, 이어하기 시 재생 0회, 참가 전 종료 손실 0, 체스/선택/베팅 중 종료 후 동일 단계 재개, 중복 복원 정산 0회, 정산 후 메인 복귀 보존, 49/50G 경계, 엔딩 대기 복원, 일반 엔딩 후 황제전 연결, 21억 금고 초과분 반환, 진엔딩 칭호 저장, 진엔딩 후 이어하기 없음, 새 게임 후 프로필 유지.
