# 08 · 구현된 게임 흐름

`chess → selection → betting → result`를 판 상태로 사용한다. 새 전체 게임은 각1000골드, 각 참가금20으로 시작한다. 기존 저장이 유효하면 현재 상태를 그대로 복구한다.

## 상태 전이

| 상태 | 입력과 종료 조건 | 다음 상태 |
|---|---|---|
| chess | 플레이어 합법 수·내장 컴퓨터 응수 | 메이트/5기물/무승부이면 selection |
| selection | 자기 생존5장 선택, 컴퓨터 패 선택 완료 | betting |
| betting | 체크/콜/레이즈/올인/폴드 | 베팅 종료 시 result |
| result | 잔액20 이상 양측이면 다음 판 | 재배정 후 chess |
| result | 어느 쪽이든20 미만 | 전체 게임 종료, 새 게임 버튼 |

체스 종료 후 마지막 판과 결과를 보여주고 확인 버튼으로 카드 선택을 연다. 체스 배당은 확정하되 포커 종료까지 잠근다. 새 판의 참가금은 체스15·포커5로 나뉜다. 참가금만으로 이미 한쪽이 올인이라면 선택 확정 직후 추가 베팅 없이 쇼다운으로 넘어간다. 체크 두 번, 인상에 대한 콜, 짧은 올인 콜, 폴드로 베팅이 닫힌다.

## 저장과 재진입

수순, 카드, 판돈, 선택 패, 최종 정산을 하나의 상태 객체로 보존한다. 결과 상태에는 이미 계산된 정산이 포함되며 다시 행동할 수 없다. 결과 기록은 판 ID로 중복 삽입을 방지한다. 손상된 저장은 복구용 키로 남기고 새 게임으로 시작한다.

## 메뉴

Play는 이어하기다. 새 전체 게임은 확인 후 현재 판을 교체하되 완료 기록은 유지한다. Exit는 일시정지 메뉴를 유지하고 탭을 닫도록 안내한다. 브라우저 탭을 강제 종료하지 않는다. 메뉴 중에는 상대의 다음 수·베팅을 실행하지 않는다.
