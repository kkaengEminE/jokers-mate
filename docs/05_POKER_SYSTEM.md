# 05 · 포커 시스템

> Phase 1 설계 이력입니다. 후속 구현 요청에 따른 현재 적용값·상태는 [15_PROTOTYPE_DECISIONS](15_PROTOTYPE_DECISIONS.md)를 우선 참조하세요. 당시 승인 대기 표시는 역사적 기록으로 보존합니다.

## 확정 범위

체스 종료 후 각자 생존 기물에서 정확히 5장을 선택한다. 5개만 생존하면 선택 여지가 없고, 더 많으면 임의의 5개를 선택한다. 킹/퀸 카드 포함은 의무가 아니다. 캡처 카드는 제외한다. 조커는 합법 패의 가치를 최적화하는 와일드카드다. 폴드는 상대에게 경합 팟을 주되 폴드한 패는 공개하지 않는다.

족보는 높은 순으로 로열 플러시, 스트레이트 플러시, 포카드, 풀하우스, 플러시, 스트레이트, 트리플, 투페어, 원페어, 하이카드다. 로열 플러시는 A-high 스트레이트 플러시의 최상위 표현으로 볼 수 있다. 무늬 우선순위 **♠ > ♦ > ♥ > ♣(스다하클)** 은 확정된 커스텀 규칙이다. 어떤 카드의 무늬를 언제 비교할지는 아래 제안이다.

## P01 · 조커 제약 후보 — 승인 대기 / Q03

각 조커를 표준 52장 중 한 카드의 가상 랭크/무늬로 치환한다. 자기 최종 5장 안에서 동일 랭크·무늬의 가상 카드가 중복될 수 없으며 두 조커도 서로 같은 카드가 될 수 없다. 최대 4개의 같은 랭크만 가능하므로 파이브 오브 어 카인드를 제외한다.

상대 패, 캡처 카드, 미배정 카드에 해당 실물이 있는지는 치환 가능 여부에 영향을 주지 않는 **자기 패 내부 제약**을 제안한다. 전역 실물 배정을 기준으로 제한하면 비공개 상대 정보가 합법 평가에 관여하고, 캡처 공개로 조커 가치가 변할 수 있다. 이 대안은 별도 디자인 결정이며 실물 배정 중복 금지와 혼동하지 않는다.

조커 0/1/2장의 모든 합법 치환 후보 중 아래 비교 키가 최대인 것을 택한다. 자연 패 우선이나 조커 수가 적은 패 우선은 추가하지 않는 안이다. 동등한 최적 치환이 여러 개면 조커 실물 ID 순서에 따라 가상 카드의 고정 랭크/무늬 순서로 대표 표현만 선택한다. 이 표현 결정은 승자를 바꾸지 않는다.

## P02 · 랭크 비교 키 후보 — 승인 대기 / Q03

A는 일반적으로 14, K=13, Q=12, J=11이다. A-2-3-4-5는 5-high 스트레이트로 인정하고 A는 이 경우에만 1로 정규화한다. Q-K-A-2-3 등 순환 스트레이트는 인정하지 않는다. 10-J-Q-K-A 동무늬만 로열 플러시다.

| 족보 | 무늬 비교 이전에 내림차순 사전식 비교할 랭크 키 |
|---|---|
| 로열/스트레이트 플러시 | 최고 랭크(휠은 5) |
| 포카드 | 네 장 랭크, 키커 |
| 풀하우스 | 트리플 랭크, 페어 랭크 |
| 플러시 | 다섯 랭크 내림차순 |
| 스트레이트 | 최고 랭크(휠은 5) |
| 트리플 | 트리플 랭크, 키커 둘 내림차순 |
| 투페어 | 높은 페어, 낮은 페어, 키커 |
| 원페어 | 페어 랭크, 키커 셋 내림차순 |
| 하이카드 | 다섯 랭크 내림차순 |

족보 등급 → 랭크 키 전체 → 무늬 키 순으로 비교한다. 약한 페어가 강한 무늬만으로 높은 페어를 이기지 않는다.

## P03 · 결정적 무늬 비교 후보 — 승인 대기 / Q03

랭크 키가 같을 때만 비교용 카드 순서를 만든다. 포카드/트리플/페어 계열은 위 키의 그룹 순서로 정렬하며 같은 랭크 그룹 안에서는 ♠♦♥♣ 순으로 정렬한다. 스트레이트 계열은 높은 카드부터(휠 5,4,3,2,A), 플러시/하이카드는 랭크 내림차순으로 둔다. 그 순서의 무늬 5개를 사전식 비교한다.

다섯 무늬까지 같으면 **진정한 동률**이다. 조커가 있는 경우에도 단독 승자가 항상 나온다는 증명을 아직 수행하지 않았으므로 평가기가 동일 키 입력을 받는 경우를 명시한다. 동률은 팟을 균등 분할하는 안을 제안하며 06의 하한을 그 다음 적용한다. 조커 ID나 플레이어 ID를 승패에 쓰지 않는다. 자연 패 우선, 최고 카드 하나의 무늬만 비교하는 대안은 미승인이다.

## 베팅 경계 — Q05

체크는 추가 콜 의무가 없을 때, 콜은 상대 기여 수준을 맞출 때, 베트/레이즈는 기여 수준을 높일 때라는 문서상 의미다. 올인은 남은 투입 가능 골드 전부를 선언하는 행동이다. 구체적 최소 베트/레이즈, 짧은 올인 이후 재레이즈 허용, 선행 플레이어, 라운드 수, 선택 변경 금지 시점은 미정이다.

미대응 금액은 경합 팟이 아니며 06 제안에서 원소유자에게 반환한다. 폴드는 베팅 합법성을 우회하는 임의 정산 요청이 될 수 없다. 베팅이 끝나지 않았는데 불균등 기여라는 이유만으로 쇼다운을 진행해서는 안 된다.
