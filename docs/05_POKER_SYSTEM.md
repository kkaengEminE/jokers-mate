# 05 · 포커 시스템

## 패 고르기

체스가 끝나면 각자 생존 기물의 카드 중 정확히 5장을 고른다. 5개만 살아 있으면 사용할 카드는 정해져 있지만 공개 순서는 선택한다. 킹·퀸 카드를 꼭 넣을 필요는 없고, 잡힌 카드는 쓸 수 없다. 패를 확정한 뒤에는 바꿀 수 없다. 화면은 최적 패를 추천한다.

## 공개 순서

자신은 확정한 5장을 모두 본다. 선택한 순서의 첫 3장을 공개하고 마지막 2장은 쇼다운까지 숨긴다. 추천 패도 순서를 표시하며 확정 전에 재선택할 수 있다. 상대는 자신의 최적 5장을 고르고 공개 순서를 무작위 확정한다. 패 확정 뒤 카드와 순서를 바꾸지 않는다.

1. 양측 첫 장 동시 공개 → 베팅 1/3.
2. 첫 라운드 종료 → 두 번째 장 공개 → 베팅 2/3.
3. 두 번째 라운드 종료 → 세 번째 장 공개 → 베팅 3/3.
4. 마지막 라운드 종료 → 남은 두 장 공개·승패 판정.

새 카드나 공동 카드는 추가하지 않는다. 공개되는 정보로 판단을 바꾸는 5장 포커다.

## 족보

높은 순: 로열 플러시, 스트레이트 플러시, 포카드, 풀하우스, 플러시, 스트레이트, 트리플, 투페어, 원페어, 하이카드.

- 랭크: A=14, K=13, Q=12, J=11, 숫자는 그대로.
- A-2-3-4-5는 5-high 스트레이트로 인정한다(이때만 A=1). Q-K-A-2-3 같은 순환 스트레이트는 없다.
- 10-J-Q-K-A 같은 무늬만 로열 플러시다.
- 파이브 오브 어 카인드는 없다.

## 조커

- 각 조커는 표준 52장 중 한 장의 가상 카드로 바뀐다.
- 자기 패 5장 안에서 같은 랭크·무늬의 카드가 겹칠 수 없다. 두 조커끼리도 같은 카드가 될 수 없다.
- 상대 패·잡힌 카드·미배정 카드에 같은 실물이 있어도 치환에 영향을 주지 않는다(자기 패 내부 제약만).
- 가능한 모든 합법 치환 중 가장 강한 패를 고른다. 자연 패나 조커가 적은 패를 우대하지 않는다.

## 승패 비교

**족보 → 랭크 키 → 무늬 키** 순으로 비교한다. 약한 페어가 무늬만으로 높은 페어를 이기지 않는다.

| 족보 | 랭크 키(내림차순 비교) |
|---|---|
| 로열/스트레이트 플러시 | 최고 랭크(5-high는 5) |
| 포카드 | 네 장 랭크, 키커 |
| 풀하우스 | 트리플 랭크, 페어 랭크 |
| 플러시 | 다섯 랭크 |
| 스트레이트 | 최고 랭크(5-high는 5) |
| 트리플 | 트리플 랭크, 키커 둘 |
| 투페어 | 높은 페어, 낮은 페어, 키커 |
| 원페어 | 페어 랭크, 키커 셋 |
| 하이카드 | 다섯 랭크 |

랭크 키가 같으면 비교용 카드 순서를 만들어 무늬 5개를 차례로 비교한다. 무늬 순위는 **♠ > ♦ > ♥ > ♣**.
- 포카드·트리플·페어 계열: 위 랭크 키의 묶음 순서, 같은 랭크 안에서는 ♠♦♥♣ 순.
- 스트레이트 계열: 높은 카드부터(5-high는 5,4,3,2,A).
- 플러시·하이카드: 랭크 내림차순.

한 덱에서 서로 겹치지 않는 두 패는 이 비교로 항상 승패가 갈리므로 **포커 무승부는 없다.**

## 베팅

| 항목 | 규칙 |
|---|---|
| 라운드 | 총 3회, 공개 1장·2장·3장 시점 |
| 선행 | 각 라운드 홀수 판은 플레이어, 짝수 판은 컴퓨터 |
| 행동 | 체크(맞출 금액 없을 때), 베트/레이즈, 콜, 폴드, 올인 |
| 최소 베트/레이즈 | 각 라운드 20G로 시작, 라운드 안에서는 직전 정규 인상폭 이상 |
| 짧은 올인 | 허용. 이미 행동한 상대의 레이즈 권한을 다시 열지 않음 |
| 베팅 가능액 | 아직 판에 넣지 않은 금고 금액. 체스 배당은 이 판 베팅에 쓸 수 없음 |
| 종료 | 체크-체크, 레이즈에 대한 콜, 짧은 올인 콜, 폴드 |

- 체크-체크 또는 베팅-콜은 해당 라운드를 끝낸다. 마지막 라운드만 쇼다운하며, 다른 라운드는 다음 공개로 진행한다. 레이즈가 진행 중이면 공개하지 않는다.
- 참가금만으로 이미 한쪽이 올인이면 패 확정 직후 추가 베팅 없이 쇼다운한다.
- 상대가 맞추지 못한 금액은 원래 주인에게 돌려준다.
- 베팅이 끝나지 않았는데 금액이 다르다는 이유만으로 쇼다운하지 않는다.
- 폴드하면 포커 몫을 상대에게 넘긴다. 공개한 카드는 유지하고 남은 비공개 카드는 숨긴다.
- 맞춰진 올인으로 추가 베팅이 불가능하면 바로 쇼다운한다. 라운드별 참가금은 없다.

이 베팅 값들은 현재 기본값이며 플레이 테스트 후 조정할 수 있다.
