# 02 · 통합 게임 규칙

## 용어

| 용어 | 뜻 |
|---|---|
| 판(대국) | 참가금 예치 → 체스 → 카드 선택 → 포커 → 최종 정산까지 |
| 전체 게임(이야기) | 한 상대와 판을 반복하다가 어느 한쪽이 참가 불가가 될 때까지 |
| 참가금 | 판마다 각자 내는 20G (체스몫 15G + 포커몫 5G) |
| 금고 | 각자 아직 판에 넣지 않은 금화 |

## 한 판의 흐름

1. 각자 금고에서 20G를 중앙에 예치한다. 판 시작 전 잔액이 20G 미만이면 참가할 수 없다(정확히 20G면 참가 가능).
2. 54장 덱에서 서로 다른 카드 32장을 양쪽 16기물에 배정한다. 자세한 조건은 [03 카드](03_CARD_SYSTEM.md).
3. 표준 체스를 둔다. 체크메이트·표준 무승부·어느 한쪽 5기물 도달 중 하나로 즉시 끝난다. 자세한 판정은 [04 체스](04_CHESS_SYSTEM.md).
4. 체스 결과로 받을 몫만 확정한다. 이 시점에는 금화를 지급하지 않는다.
5. 각자 생존 기물의 카드 중 정확히 5장을 고르고, 1회 베팅 후 쇼다운 또는 폴드로 포커 승자를 정한다. 자세한 내용은 [05 포커](05_POKER_SYSTEM.md).
6. 미매칭 금액 반환, 체스 배당, 포커 배당을 합쳐 **한 번만** 정산한다. 자세한 계산은 [06 경제](06_ECONOMY_SYSTEM.md).
7. 정산 후 잔액이 20G 미만인 쪽은 전체 게임에서 패배한다.

## 핵심 규칙 요약

- **체스와 카드:** 킹은 잡히지 않는다. 승격은 이동 역할만 바꾸고 카드 정체는 유지한다. 포커 패에 킹·퀸 카드를 꼭 넣을 필요는 없다.
- **5기물 종료:** 어느 쪽이든 기물이 5개가 되는 수 직후 체스가 끝난다. 그 수가 상대 킹에 체크를 남기면 수를 둔 쪽 승리, 아니면 무승부. 체크메이트가 우선한다.
- **공개 정보:** 자기 카드는 모두 보인다. 상대 생존 카드는 잡거나 쇼다운하기 전까지 비공개다. 폴드한 패는 공개하지 않는다. 쇼다운에서는 선택한 5장만 공개한다.
- **포커 승패:** 족보 → 랭크 → 무늬(♠ > ♦ > ♥ > ♣) 순으로 비교하며 무승부는 없다.
- **정산:** 체스 승자는 양측 체스몫 30G, 포커 승자는 양측 포커몫 10G와 유효 추가 베팅을 받는다. 체스 무승부면 40G 전부가 포커로 넘어간다. 최종 잔액 보호 같은 보정은 없다.

## 추가 베팅이 없을 때의 손익

| 내 체스 | 내 포커 | 내 순손익 |
|---|---|---:|
| 승 | 승 | +20G |
| 승 | 패·폴드 | +10G |
| 패 | 승 | −10G |
| 패 | 패·폴드 | −20G |
| 무 | 승 | +20G |
| 무 | 패·폴드 | −20G |

## 규칙 수용 기준

| ID | 검사 | 기대 |
|---|---|---|
| R01 | 체스 승자 결정 직후 | 금화 지급 없음, 받을 몫만 표시 |
| R02 | 한쪽 5기물, 체크 없음 | 체스 무승부, 포커로 전환 |
| R03 | 5기물을 만든 캡처가 체크를 남김 | 수를 둔 쪽 체스 승리 |
| R04 | 포커 패에 킹 카드 없음 | 생존 카드 5장이면 허용 |
| R05 | 잡힌 카드를 포커 패로 선택 | 거부 |
| R06 | 정산 잔액 19 / 20 | 각각 전체 패배 / 다음 판 가능 |
| R07 | 포커 폴드 | 폴드 패 비공개 |
| R08 | 같은 정산 재요청 | 중복 지급 없음 |
