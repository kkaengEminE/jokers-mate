# 02 · 통합 게임 규칙

## 용어와 확정 흐름

‘판’은 참가금 납입부터 체스, 포커, 최종 정산까지를 말한다. ‘전체 게임’은 잔액으로 다음 판 참가 가능 여부를 판단하는 연속 세션이라는 문서상 용어다. 실제 UI 명칭은 미정이다.

1. 전체 게임 시작 시 각 1000골드, 합계 2000골드.
2. 판 시작 시 각 20골드를 중앙 팟에 기여한다. 판 시작 전 잔액이 20 미만이면 즉시 전체 게임 패배, 정확히 20이면 참가 가능하다.
3. 54장 단일 덱에서 32개의 고유 실물 카드를 각 16기물에 배정한다.
4. 표준 합법 체스를 진행하며 이전 표준 종료 또는 어느 한쪽 생존 5기물에 도달하면 즉시 체스를 끝낸다.
5. 체스 결과만 기록한다. 팟을 지급하지 않는다.
6. 생존 기물에서 정확히 카드 5장을 선택하고 포커 베팅/쇼다운 또는 폴드로 포커 결과를 결정한다. 선택 확정과 베팅의 세부 순서는 Q05다.
7. 미대응 기여금 처리, 유효 팟 분배, 보호금 처리를 포함하여 **한 번의 최종 정산**을 수행한다.
8. 정산 잔액이 20 미만인 플레이어는 전체 게임에서 즉시 패배한다.

## 체스와 카드의 결합

체스 킹은 항상 생존하며 잡을 수 없다. 승격은 이동 역할만 바꾸고 기존 카드 정체성을 유지한다. 킹/퀸 기물의 초기 카드 배정 제한은 승격 기물에 재적용하지 않는다(기존 정체성 유지에서 도출). 포커에 킹이나 퀸 카드를 반드시 포함할 필요는 없다.

어느 쪽이든 5기물이 되는 합법 수 직후 종료하므로 정상 진행에서 4기물로 떨어지는 다음 수는 존재하지 않는다. 조기 체크메이트나 표준 무승부라면 양측 모두 5개보다 많이 남아도 포커로 전환한다.

## 체스 결과 결정

동시에 체크메이트가 발생하면 체크메이트가 우선한다. 그렇지 않고 합법 캡처로 5기물이 되면서 상대에게 체크가 걸리면 체크를 건 쪽이 즉시 체스 승리한다. 상대가 다음 수로 체크를 피할 수 있어도 동일하다. 체크 없이 5기물이 되면 무승부다. 체크를 벗어나는 캡처라도 수를 둔 뒤 상대에게 체크가 없다면 무승부다.

다른 표준 무승부 조건과 특수 체크 승리가 같은 수에서 동시에 성립하는 순서는 명세에 없다(Q02). 이전 수에서 이미 확정된 종료를 되돌리지는 않는다.

## 공개 정보

자신의 모든 카드 정체성은 보인다. 상대의 생존 카드 정체성은 캡처 또는 쇼다운 전까지 비공개다. 캡처 카드는 공개하되 포커 참가 자격을 잃는다. 폴드한 패는 공개하지 않는다. 쇼다운에서 미선택 생존 카드까지 공개할지는 Q04다. AI는 자기 카드와 공개된 정보만 사용한다.

## 경제 규칙 요약

체스 승자 보호는 최종 잔액의 최소 20이다. 기존 미베팅 자금만으로 20 이상 남는다면 20을 추가 지급하지 않는다. 체스 무승부에는 보호도 참가금 반환 특혜도 없다. 포커 승리는 모든 미베팅 자금의 몰수를 의미하지 않으며 유효한 판돈만 획득한다. 양측 완전 투입 시 예시는 20/1980 또는 무승부 체스에서 2000/0이다.

폴드 시 경합 팟은 상대에게 간다. 다만 체스 승자의 하한을 폴드에도 적용하는 정밀 방식, 미대응 금액 반환, 동률 분배는 06의 승인 대기 알고리즘으로 구분한다.

| R01 | 체스 승자 결정 직후 | 골드 지급 없음 |

| R06 | 정산 19 / 20 | 각각 전체 패배 / 다음 판 가능 |
| R07 | 포커 폴드 | 폴드 패 비공개 |
