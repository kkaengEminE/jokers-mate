갱신: 2026-10-21. 사용자는 권장안 제시 후 “게임 구현까지 해줘”라고 요청했고 이어서 계속 진행을 지시했다. 아래는 현재 실행 코드의 선택이며, 읽을 수 없었던 과거 답변이 복원되었다는 뜻이 아니다.

## 제시한 권장안의 적용

- Q01: 미대응 반환→유효 팟 분배→체스 승자에게 부족한20만 팟에서 보호. 보호 후 재매칭하지 않는다. 폴드에도 하한을 적용한다.
- Q02: 체크메이트→5기물 특례→기타 종료. 체크를 벗어난 수라도 수를 둔 후 상대에게 체크가 없으면5기물 무승부.
- Q03: 패 내부 가상 카드 중복 금지, 파이브카인드 제외, A2345 허용. 족보→랭크 키→무늬 전체 키. 최종 동일 키는 분할. 자연 패 우대 없음.
- Q04: 쇼다운 선택5장만 공개, 폴드 패와 미선택 생존 카드는 완료 기록에 공개하지 않는다.

## 최초 수 뒤 멈춤 대응

사용자 스크린샷의 메시지는 Worker 오류 처리에서 발생했다. 조사 시 개발 서버5173의 리스너가 없고 브라우저 개발 연결 오류가 확인되었다. 화면 캐시만 남은 상태에서 첫 차례의 Worker 파일을 불러오지 못하는 경로가 존재했다. 당시의 모든 네트워크 이벤트가 보존된 것은 아니므로 그 순간의 개별 실패 응답 코드는 단정하지 않는다.

수정: Worker 의존 제거, 내장 로직 초기 번들 포함, 조합 선택 분할 실행, 판 변경 시 작업 취소, 계속 실행되는 프로덕션 로컬 서버. 화면의 AI 표기도 ‘컴퓨터·초급’으로 바꿨다. 원격 AI 서비스는 처음부터 사용하지 않았다.
