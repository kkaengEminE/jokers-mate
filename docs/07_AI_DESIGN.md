# 07 · 내장 컴퓨터 상대

## 실행 방식

상대는 생성형 AI 서비스가 아니라 TypeScript로 작성한 로컬 탐색 로직이다. API 키나 외부 호출을 쓰지 않는다. 계산 코드는 초기 번들에 포함되어 별도 Worker나 네트워크 없이 실행된다. 포커 최적 조합 탐색은 약 12ms 단위로 브라우저에 제어를 돌려주며, 판이나 단계가 바뀌면 취소한다. 화면에는 ‘컴퓨터·초급’으로 표기한다.

## 체스

합법 후보 수마다 상대의 합법 응수를 한 수 더 살피는 2-ply 탐색이다. 체크메이트, 6→5 캡처와 체크 특례를 우선 점수화한다. 기물 가치, 캐슬링, 중앙 이동과 함께 자기 카드의 랭크·페어 가능성·같은 무늬·연결 랭크·조커 보존을 고려한다. 약간의 난수로 같은 진행 반복을 줄인다. 목표는 3/10 초급이며 Elo를 보장하지 않는다.

## 정보 경계

컴퓨터 입력은 공개 FEN, 자기 색, 자기 카드 배정만 포함한다. 플레이어의 숨은 카드 배정은 전달하지 않는다. 기물 역할과 위치, 잡힌 카드는 공개 정보다. 플레이어 카드를 섞어도 컴퓨터 입력이 바뀌지 않는 회귀 테스트를 둔다.

## 포커

생존 카드의 모든 5장 조합을 합법 조커 치환과 함께 평가해 최적 패를 고른다. 베팅은 자기 패 등급, 공개된 투입액·잔액, 콜 부담, 직전 레이즈 폭, 가능한 행동, 난수만 사용한다. 약한 패로 큰 콜 부담을 만나면 폴드하고, 강한 패와 일부 약한 패로 베트/레이즈한다. 정밀한 상대 모델링은 없다.

## 오류 처리

컴퓨터 수는 입력 시점의 상태 사본으로 계산하고, 같은 판·같은 수순 길이일 때만 반영한다. 메뉴·일시정지 중에는 대기 중인 체스·베팅 행동을 취소한다. 계산 실패는 정상 ‘생각 중’ 표시와 구분해 보여주고 복구 버튼을 제공한다.
