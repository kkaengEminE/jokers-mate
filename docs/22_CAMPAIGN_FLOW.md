# 이야기·저장·엔딩 진행 명세 — R3

2026-10-22. 사용자 요청을 기록. **계획이며 현재실행코드에 전체반영됐다는 뜻이 아니다.**

## 1. 프롤로그와 메인
새 게임을 생성할 때만 프롤로그1회. ‘시작하기’를 누를 때마다재생하지 않는다. 계속하기·다음대국·메인복귀로재생금지. 새 게임을처음부터선택하면 새이야기라 다시재생(건너뛰기가능). 이미본문을보았는지 저장. 설정에서 다시보기는 보조기능후보.

메인: 새로하기 / 이어하기(이어갈이야기있을때) / 설정 / 종료. 새로하기는 진행중이야기덮어쓰기확인. 종료된진엔딩이후에는 이어하기없음. 캐릭터소개·칭호·업적·기록은 새게임과별개영구프로필.

## 2. 상태와 버튼
| 상태 | 주요버튼 | 저장/복귀 |
|---|---|---|
|프롤로그|다음·건너뛰기|시청진도,아직참가금없음|
|참가확인|20G내고대국시작·돌아가기|아직미납,안전종료|
|체스|합법수·일시정지|진행스냅샷+미완료판마커|
|체스결과|포커로이동|최종정산전,나가면도주|
|카드선택/베팅|선택확정/합법베팅|최종정산전,나가면도주|
|쇼다운/정산연출|연출건너뛰기|결과먼저원자적저장,이미확정된승리박탈금지|
|정산·양쪽20이상|계속하기·돌아가기|계속=참가확인;돌아가기=메인|
|정산·상대20미만|**엔딩보기만**|계속/돌아가기없음;재실행도승리엔딩대기|
|정산·내20미만|실패 화면·메인으로|이어하기 삭제;새 게임은 로언부터|
|로언엔딩|돌아가기|본문시청완료후메인;황제해금정책아래참조|
|황제진엔딩|돌아가기|본문시청완료후메인;이어하기제거;황제칭호해금|

일시정지의 ‘계속하기’는 아직세션을떠나지않았으므로그자리복귀. ‘저장하고메인으로’라는 안전종료버튼을활성판에두지않는다. 대신 ‘대국포기하고메인으로—현재판돈XXG손실’ 확인. 미완료판을꺼서유리한상태로되돌리는것금지. 기록을읽는시간·일시정지만으로패배하지않는다.

## 3. 이어하기와 도주의 일관성
‘이전부터이어감’은 이야기와잔액을유지한다는뜻. 활성판을종료했다면 그판은도주패배정산한후 그결과에서이어간다. 이긴상태로재개하거나 참가금을다시차감하지않는다.

각판ID·이야기ID·계약버전·상대ID·원장·phase·resultCommitted·resultAcknowledged·endingViewed 저장. 결과계산/잔액변경/판마커해제는한트랜잭션. 다시열기·탭중복·이중클릭으로중복정산금지. 저장실패는새판입장중단. 두탭동시게임은한탭만활성화.

요청의 ‘승으로확인되지않고껐다면패배’에대해 결과확정과화면확인을구분해야한다. **제안:**정산원장이이미확정되었으면결과화면을안봤어도보존;계산전미완료판만도주. 그렇지않으면표시중앱충돌로이미딴돈이취소된다. 최종확인버튼누르기전까지도주로할지는미결항목.

## 4. 로언 이후 황제
황제명 제안: **아우렐리온(Aurelion)**. 기존카드덱의추가카드가아닌상대아바타. 조커의모습,킹과퀸을결합한이중왕관. 시작금고 **2,100,000,000G**. 로언의이야기엔딩후메인‘이어하기’가이황제전으로연결됨. 별도승인없이체스/포커특수능력을추가하지않는다.

사용자는후속 답변으로 확정했다. **로언을 파산시킨 승리 엔딩 후에만 황제전이 열린다.** 한 판 승리는 엔딩 없이 다음 대국으로 간다. 내 잔액은 그대로 이월한다. 실패 후 황제전 개방이나 자금1000 보충은 적용하지 않는다.

**황제도 잔액20G 미만이면 파산이며 진엔딩 조건 충족.** 0G까지 따야 하는 조건은 없다. 남은1~19G도 몰수하지 않는다.

**내 파산은 언제나 전체 게임 오버.** 로언전/황제전 모두 이어하기를 제거한다. 실패 화면 뒤 새 게임은 로언·각1000G·새 프롤로그부터. 황제전 체크포인트 부활은 없다. 승리 엔딩만 일반엔딩/진엔딩으로 부르며 실패 화면과 구분한다.

## 5. 일반엔딩과진엔딩
로언승리:리브가이름장부를되찾음. 로언이왕실의초대를건네며황제의존재를예고. 돌아가기후이어하기로새상대진입. 기존‘완전한최종결말’이아닌1막의완결로수정.

황제승리진엔딩:황제의금고가참가불가→이중왕관이벗겨짐→리브에게왕좌의권리가넘어감→새황제의초상→크레딧→돌아가기. 로언엔딩화면이나대사를재사용해이름만교체하지않는다. 최종텍스트/일러스트는추후디자인결정.

진엔딩완료시영구프로필title=황제. 설정→캐릭터소개에서 **리브 · 황제**의칭호를황금빛으로표시. 초상은킹/퀸이중왕관을쓰고거대한체스·카드왕좌에앉은리브로교체. 메인에는이어하기없고새로하기. 새로해도프로필칭호는유지(초기화는별도명시적행동).

## 6. 왕좌 아트 브리프 — 제작보류
모티브는낮고정돈된의자가아닌,높이쌓인위압적인재료더미. 부서진룩의탑,비숍의곡선,나이트실루엣,거대한카드판들이비대칭적으로겹쳐지고그꼭대기에좌석. 검이나기존드라마왕좌의정확한실루엣을그대로복제하지않고우리게임재료로독자구성. 아르누보곡선/빅토리아금속세공을결합. 사용자가디자인은다시정한다고명시했으므로이번작업은브리프만저장하고이미지생성안함.

## 7. 수명과검증
황제21억은초기1000에비해압도적으로크다. 유효베팅만딸수있으므로한번의올인승리로21억을얻지못한다. 모든승부를무승부체스+최대매칭포커승리로이겨금고를두배씩키워도총자금을흡수하려면대략22회성공이필요하며실제대국은더길다. 자동성장/자금보충/강제베팅은미승인. 실제소요시간측정후조정한다.

검증항목:새게임프롤로그1회,이어하기재생0회,참가전종료손실0,체스/선택/베팅종료도주1회,중복복원정산0회,정산후메인복귀보존,19/20경계,엔딩대기복원,일반엔딩후황제라우팅,21억매칭초과반환,진엔딩칭호원자저장,진엔딩후이어하기없음,새게임후프로필유지.
